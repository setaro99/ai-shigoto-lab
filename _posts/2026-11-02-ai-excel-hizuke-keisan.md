「納期の3営業日前を出したい」「契約満了日の1か月前に色を付けたい」「入社日から勤続年数を出したい」「2026/11/2を『令和8年11月2日（月）』と表示したい」——事務の現場では、日付まわりの計算が意外と多く、そのたびに関数を調べ直している人も少なくありません。

日付の計算は、関数そのものよりも**「何を日数に数えるか」という前提の伝え方**でつまずきます。この記事では、AIにExcelの日付計算を頼むときの伝え方と、そのままコピペできるプロンプトを紹介します。

## 日付計算でつまずく3つの理由

日付の計算は、次の3点があいまいなまま依頼すると、AIも的外れな数式を返しがちです。

1. **数え方の違い**——「30日後」は暦日の30日なのか、土日祝を除いた営業日の30日なのか
2. **祝日・休業日の扱い**——祝日は別表で管理するのか、年末年始や会社の休業日も除くのか
3. **セルの中身が「本物の日付」か**——見た目は日付でも、実は文字列で入力されていると、計算も並べ替えもできない

特に3つ目は見落としがちです。計算がうまくいかないときは、数式より先に「セルの中身が日付データか」を疑うのが近道です。

## 考え方：日付の依頼は「起点・数え方・表示」の3点セットで

AIに頼むときは、次の3つを書けば、ほぼ一度で使える数式が返ってきます。

| 伝える内容 | 例 |
|---|---|
| 起点 | A列に受注日が入っている（2行目〜500行目） |
| 数え方 | 土日と、「祝日」シートの日付を除いた営業日で数える |
| 表示 | 結果は「2026/11/02（月）」の形で表示したい |

あわせて、使っているExcelの種類（Microsoft 365か、古い版か）も添えると、バージョンで使えない関数を案内されにくくなります。

## コピペで使えるプロンプト①：営業日で期限を出す

【 】の中を書き換えて、ChatGPT・Copilot・Gemini・Claudeなど使い慣れたAIに貼り付けてください。

```
あなたはExcelに詳しい事務サポート担当です。
日付の計算式を作ってください。

【使っている環境】【例: Windows11 / Microsoft 365のExcel】
【起点の日付】【例: 「受注一覧」シートのA列に受注日が入っている。2行目〜500行目】
【求めたいもの】【例: 受注日から5営業日後の納期をB列に出したい】
【休みの扱い】【例: 土日は除く。祝日は「祝日」シートのA2:A40に日付が並んでいる】
【表示の形】【例: 2026/11/02（月）】

条件:
・数式は、B2セルに入れてそのままコピーできる形で書く
・祝日の範囲は、行が増えても追従するよう$を使った指定にする
・使う関数（WORKDAY系など）の役割を、1行ずつ説明する
・表示形式の設定手順も、番号付きで書く
・「起点が空欄の行」でエラー表示にならない書き方も添える
```

返ってきた数式は、一度**自分の手計算と照らして確かめてください**。たとえば金曜日を起点にした「1営業日後」が月曜日になるか、祝日をはさんだ場合に1日ずれていないか、の2点を見れば十分です。

## コピペで使えるプロンプト②：満了日・勤続年数など「期間」を出す

```
Excelで、日付と日付の間の期間を求める数式を作ってください。

【使っている環境】【例: Microsoft 365のExcel】
【データの場所】【例: C列に入社日、D列に今日の日付を基準にした勤続期間を出したい。2行目〜200行目】
【求めたいもの】【例: 「3年4か月」の形で表示したい】
【あわせて】【例: 契約満了日がE列にあり、満了の30日前から該当行を目立たせたい】

条件:
・DATEDIF関数など、月・年単位の計算に向いた関数を使う
・「年」と「月」を組み合わせて文字として表示する数式を示す
・今日の日付を基準にする場合の注意点（開くたびに結果が変わること）を説明する
・満了30日前に色を付ける場合は、条件付き書式の手順と、数式の入れ方を示す
```

「今日の日付」を使うと、ファイルを開くたびに結果が変わります。提出用の控えとして固定したいときは、**計算結果を値として貼り付ける**運用も、あわせてAIに聞いておくと安心です。

## コピペで使えるプロンプト③：和暦・曜日の表示と、文字列の日付の直し方

```
Excelの日付の表示について、2点教えてください。

【使っている環境】【例: Microsoft 365のExcel】
【やりたいこと1】【例: 2026/11/2 を「令和8年11月2日（月）」と表示したい（セルの値は日付のままにしたい）】
【やりたいこと2】【例: F列に「20261102」や「2026.11.2」の形で入力された文字列を、本物の日付に直したい】

条件:
・1は、セルの書式設定（ユーザー定義）の入れ方を、コピーできる形で示す
・2は、数式で直す方法と、「区切り位置」機能で直す方法の両方を案内する
・直したあとに、本当に日付データになったかを確かめる簡単な方法を書く
```

和暦は表示形式だけで変えられるため、**セルの値そのものは変わりません**。計算に使う列と、見せるための列を分けておくと、後から集計するときも困りません。

## 使う前に確認する4つのチェック

AIが返した数式は、そのまま本番の表に入れる前に、次の4点を確かめてください。

1. **コピーで試す**——元の表は触らず、コピーしたシートで動かす
2. **端の日付を試す**——月末、年末年始、うるう年の2月29日など、ずれやすい日を2〜3件入れて結果を見る
3. **祝日表の更新**——祝日の一覧は年が変わると古くなる。更新は人の仕事として残る
4. **社外に出す期限は人が最終確認**——契約や納期に関わる日付は、数式の結果を鵜呑みにせず、カレンダーでも確認する

なお、契約書の期間の解釈や、法律上の期限（時効・申請期限など）の計算は、AIの数式ではなく専門家や所管窓口に確認してください。ここで扱うのは、あくまで社内の日付管理を楽にするための計算です。

## まとめ

Excelの日付計算は、「起点・数え方・表示」の3点を伝えるだけで、AIがほぼ使える数式を返してくれます。つまずいたら、数式より先に**セルが本物の日付になっているか**を確かめること。祝日の更新と最終的な日付の確認だけは人の側に残し、数式づくりはAIに任せてみてください。毎月の期限管理が、少し軽くなるはずです。

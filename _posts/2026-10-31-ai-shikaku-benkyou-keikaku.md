「資格を取ろうと決めて参考書を買ったのに、最初の2週間でペースが崩れた」——仕事をしながら資格試験を目指す方に、とても多い悩みです。

原因は意志の弱さではありません。多くの場合、**計画の立て方**にあります。「毎日2時間やる」と決めても、残業や飲み会が入れば初日から破綻します。しかも一度遅れると、立て直す手間が重くなり、そのまま参考書が積まれていきます。

この記事では、簿記・宅建・FP・ITパスポートなど、試験日が決まっている資格を想定して、**AIに「崩れにくい勉強計画」を作らせる方法**を紹介します。ChatGPT・Gemini・Copilot・Claudeのどれでも使える形です。

## 解決の考え方：「理想の計画」ではなく「平日の現実」から組む

計画が崩れる最大の理由は、理想の一日を前提にしていることです。AIに頼むときは、次の4つを先に伝えます。

1. **試験日と残り日数**：ここから逆算する土台になります
2. **使える時間の現実**：「平日は30分、土日は合計3時間」のように、少なめに申告します
3. **教材と範囲**：テキスト名、章の数、過去問の年数など
4. **今の状態**：初学者か、一度落ちたことがあるか、得意・苦手分野はどこか

そのうえで、計画に次の3つの仕掛けを入れてもらうのがポイントです。

- **予備日（バッファ）**：週に1日は「何も入れない日」を作る。遅れを吸収する場所です
- **復習の再登場**：学んだ範囲が、数日後・1週間後に小さく再登場する形にする（詰め込みより定着しやすいとされる考え方です）
- **フェーズ分け**：インプット期 → 過去問期 → 総仕上げ期に分け、いつ何をするかを明確にする

AIは、表やカレンダー風の一覧に整えるのが得意です。逆に、「あなたにどの資格が向いているか」「合格できるか」は判断できません。計画づくりの下請けとして使うのがちょうどよい距離感です。

## コピペで使えるプロンプト

### ① 試験日から逆算した学習計画を作る

【 】を自分の状況に書き換えて貼り付けてください。

```
あなたは社会人向けの学習計画づくりを手伝うアシスタントです。
次の条件で、試験日までの勉強計画を作ってください。

【条件】
・資格：【例：日商簿記3級】
・試験日：【例：2026年12月6日】　今日：【例：2026年10月31日】
・使える時間：平日は【30分】、土曜は【2時間】、日曜は【1時間】
・教材：【例：テキスト全10章、過去問題集（直近8回分）】
・今の状態：【例：初学者。仕訳が苦手そう】
・仕事が忙しくなる週：【例：11月第3週は残業が多く、ほぼ0分】

【計画に必ず入れること】
1. 週に1日は「予備日」として何も入れない
2. 「インプット期 → 過去問期 → 総仕上げ期」の3フェーズに分ける
3. 学んだ範囲は、翌週に10分程度の復習として再登場させる
4. 忙しい週は最初から軽くしておく

【出力形式】
・まず全体の流れを3行で
・次に、週ごとの表（週／フェーズ／やること／目安時間）
・最後に「遅れたときのルール」を3つ
```

「遅れたときのルール」を最初に決めておくと、崩れたときに悩まずに済みます。

### ② 今日やることを「30分の一口サイズ」に割る

```
次の範囲を、平日の30分で終わる単位に分けてください。

範囲：【例：テキスト第4章「現金・預金の処理」（28ページ）】

条件：
・1回30分で、読む→問題を解く→間違いを確認、の流れが入る形
・全部で何回に分かれるかも教えてください
・各回の最後に「今日できたかを自分で確認する一問」を付けてください
```

### ③ 計画が崩れたときの立て直し

```
勉強計画が遅れました。立て直しを手伝ってください。

【元の計画】（ここに計画の表を貼る）
【現在】：試験まで残り【21日】、予定より【第3章まで】遅れている
【残りで使える時間】：平日30分、土日合計3時間

お願い：
・全部をやり直さず、「必ずやること」「余裕があればやること」「今回は捨てること」に分類してください
・配点や出題頻度が高そうな分野を優先してください（分からない場合は、その旨を明記してください）
・最終週は新しいことを学ばず、復習だけにしてください
```

「捨てる」を最初から選択肢に入れるのが、立て直しのコツです。全部を拾おうとすると、また破綻します。

### ④ 間違いノートを作る

```
次の間違えた問題を、復習用の「間違いノート」に整理してください。

【間違えた問題と、自分の答え・正解】（ここに貼る）

出力形式：
・分野
・間違えた理由（知識不足／ケアレスミス／問題文の読み違い のどれか）
・次に同じ問題が出たときの「一言ルール」
・翌週にもう一度解く用の類題を1問（作れない場合は「テキストの該当箇所を見直す」と書く）
```

## 使う前のチェック

- **試験日・出題範囲・配点は必ず公式情報で確認する**：AIは試験制度の細かい改定を知らないことがあります。試験日や出題範囲は、主催団体の公式サイトの最新情報を自分で確認してください
- **「合格できる」などの保証は受け取らない**：計画はあくまで目安です。合否の見込みはAIにも誰にも断定できません
- **著作権のあるテキストや問題を丸ごと貼らない**：章の見出しやページ数、自分の間違えた箇所の要点など、必要な範囲にとどめます
- **個人情報・勤務先の情報は入れない**：残業が多い週など、状況は一般的な表現で十分です
- **無理のある計画が出たら削る**：実際の平日30分に収まっているか、自分の目で確かめます。迷ったらさらに2割減らしてください

社会人の資格勉強が続かないのは、計画が理想の一日で組まれているからです。試験日と「平日の現実の時間」をAIに伝え、予備日・復習の再登場・フェーズ分けを入れてもらう。遅れたら「必ずやる・余裕があればやる・捨てる」に分け直す。この流れなら、崩れても立て直せます。試験の情報だけは公式サイトで確認し、計画づくりはAIに任せてみてください。

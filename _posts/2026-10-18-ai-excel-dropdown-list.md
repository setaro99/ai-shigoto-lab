「担当者名を手入力してもらったら、『田中』『田中さん』『たなか』とバラバラになった」「ステータス欄に想定外の言葉が入って、集計が合わない」——共有の管理表では、よくある悩みです。

この予防にいちばん効くのが、Excelの**ドロップダウンリスト**（プルダウン）です。選ぶだけの形にすれば、そもそも違う表記が入りません。ただ、「データの入力規則」の画面は選択肢が多く、リストの元データの指定や、2つのリストを連動させる方法でつまずく人が少なくありません。この記事では、**やりたいことを日本語で伝えて、AIに手順と数式を作ってもらう方法**を紹介します。

## つまずくのは「機能」ではなく「前提の伝え方」

ドロップダウンの基本は「入力規則で、リストを選ぶ」だけです。難しく感じる原因は、次の3点にあります。

1. **選択肢の置き場所**——その場で「はい,いいえ」と直接入力するのか、別シートの一覧を参照するのかで手順が変わる
2. **選択肢が増えたときの追従**——担当者が1人増えたとき、リストの範囲も自動で広がるようにしておかないと、新しい名前が選べない
3. **連動させたい場合**——「部署を選ぶと、担当者の候補がその部署の人だけになる」といった二段階の選択は、数式（INDIRECT関数など）が必要になる

AIに頼むと、この3点を自分の表の状況に合わせて整理してくれます。そのために、**どこに何が入っているか**を具体的に伝えるのが近道です。

## 伝えるべき情報は5つだけ

| 伝える内容 | 例 |
|---|---|
| 環境 | Windows／Mac、Microsoft 365など |
| ドロップダウンを付けたいセル | C列の2行目〜300行目 |
| 選択肢の内容と置き場所 | 別シート「マスタ」のA列に担当者名が入っている |
| 選択肢の増減 | 年に数回、人が増える |
| 入力ミスへの対応 | リスト外の入力は拒否／警告だけ出す |

## コピペで使えるプロンプト①：基本のドロップダウンを作る

【 】の中を書き換えて、ChatGPT・Copilot・Gemini・Claudeなど使い慣れたAIに貼り付けてください。

```
あなたはExcelに詳しい事務サポート担当です。
セルをドロップダウンリストで選べるようにしたいです。設定手順を教えてください。

【使っている環境】【例: Windows11 / Microsoft 365のExcel】
【付けたいセルの範囲】【例: 「案件一覧」シートのC列、2行目〜300行目】
【選択肢の置き場所】【例: 「マスタ」シートのA2から下に担当者名が並んでいる（現在12人）】
【選択肢の増減】【例: 年に数回、人数が増える】
【リスト外が入力されたとき】【例: エラーで拒否したい】

条件:
・「データ」タブからの操作を、番号付きの手順で書く（バージョンで名称が違う場合は、その旨も書く）
・選択肢が増えても自動で範囲が広がるよう、「テーブル」化または名前の定義を使う方法を案内する
・「元の値」に入れる内容を、そのままコピーできる形で示す
・エラーメッセージの文面例も1つ付ける
```

選択肢が増える表では、元データを**テーブル（Ctrl+T）にして名前を付けておく**と、行を足すだけでリストにも反映されます。AIの案内がこの方式になっているか、確認してみてください。

## コピペで使えるプロンプト②：2つのリストを連動させる

「部署を選ぶと、担当者の候補が絞られる」という使い方です。

```
Excelで、2つのドロップダウンを連動させたいです。手順と数式を教えてください。

【使っている環境】【例: Microsoft 365のExcel】
【1つ目のリスト】【例: B列。営業部／総務部／経理部のいずれか】
【2つ目のリスト】【例: C列。B列で選んだ部署に所属する人だけを候補にしたい】
【元データの置き場所】【例: 「マスタ」シートに、1行目が部署名、その下に各部署の担当者名が縦に並んでいる】

条件:
・INDIRECT関数を使う方法を基本に、手順を番号付きで書く
・名前の定義の付け方（部署名をそのまま名前にする）を具体的に示す
・部署名にスペースや記号が入っている場合の注意点を書く
・新しい部署や担当者が増えたときの更新手順も書く
```

返ってきた「元の値」は、たとえば `=INDIRECT($B2)` のような形です。**1つ目のリストの選択肢と、名前の定義が一字一句一致している**ことが動作の条件なので、そこはAIの説明を見ながら確かめましょう。

## コピペで使えるプロンプト③：選択肢が出ない・おかしいとき

```
Excelのドロップダウンリストが思いどおりに動きません。原因の候補を可能性が高い順に挙げ、確認方法と直し方を教えてください。

【やりたいこと】【例: C列で担当者名を選べるようにしたい】
【入力規則の「元の値」に入れた内容】【例: =マスタ!$A$2:$A$13】
【実際に起きていること】【例: 矢印は出るが、最近追加した人が候補に出ない／矢印がそもそも出ない】
【補足】【例: シートは保護している／別ファイルのリストを参照している】

条件:
・範囲の指定ずれ、「セルに入力規則の矢印を表示する」の設定、保護や外部参照の影響を必ず確認する
・直し方は画面の操作で、順番に書く
```

意外に多い原因は、追加した名前がリストの範囲の**外**にあること（上の例なら13行目までしか指定していない）と、貼り付けで入力規則が上書きされていることです。

## 設定したあとの4つのチェック

1. **実際に選んでみる**——矢印が出るか、リスト外の文字を入れて拒否または警告が出るかを、1セルで試します
2. **コピー＆貼り付けに注意する**——他のセルから「通常の貼り付け」をすると、入力規則が消えることがあります。共有する人には「値の貼り付け」を案内しておくと安心です
3. **選択肢を増やす手順を書き残す**——担当者が増えたとき、どこに追加すればよいかを、表の端やシートのメモに1行残しておきます
4. **実データを貼らない**——AIには列の構成と選択肢の種類（「担当者名」など）だけを伝えれば十分です。社員名や顧客名そのものは貼らず、「A氏」などに置き換えて相談してください

## まとめ

ドロップダウンリストは、**「どのセルに、どこにある選択肢を出し、増えたときはどうするか」**を日本語で説明できれば、設定手順や数式はAIが作ってくれます。ポイントは、選択肢をテーブルなどで管理して追従させること、連動リストは名前の一致を確認すること、設定後は必ず1セルでテストしてから共有することです。

入力のルールを人に頼むのではなく、表の側に持たせる。それだけで、集計前の「表記ゆれ直し」の時間はぐっと減ります。まずは、いちばんバラつきやすい1列にだけ設定してみてください。

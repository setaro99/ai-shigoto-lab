会議が終わり、議事録はなんとか書き上げた。ところが最後に待っているのが「送付メール」です。ファイルを添付して「議事録を送ります」とだけ書くと、参加者はおそらく開いてくれません。かといって、毎回きちんとした文面を考えるのも手間がかかります。

議事録を送る目的は「記録を渡すこと」ではなく、**決まったことと、各自がやることを全員に同じ認識で持ってもらうこと**です。この記事では、AIを使って、本文を読むだけで要点が伝わる送付メールを短時間で作る方法を紹介します。議事録そのものの清書は[別記事]({{ site.baseurl }}{% post_url 2026-07-14-ai-gijiroku-seisho %})で扱っているので、ここでは「送るメール」に絞ります。

## 議事録の送付メールが読まれない理由

添付だけで済ませたメールが読まれにくいのには、理由があります。

- 本文を読んでも、**自分に関係あるのかどうか**がわからない
- 決定事項や期限が添付ファイルの中に埋もれている
- 件名が「議事録」だけで、どの会議かすぐ判別できない
- 参加しなかった人に、背景が伝わらない

つまり、送付メールの本文は「添付ファイルの案内」ではなく、**議事録の3行要約＋依頼事項の一覧**として作るほうが機能します。

## 解決の考え方：本文は「決定・依頼・期限」の3点だけ

議事録の送付メールには、次の順で書くと迷いません。

1. **何の会議か**（日時・会議名。件名にも入れる）
2. **決まったこと**（多くても3点まで）
3. **誰がいつまでに何をするか**（担当・期限・内容）
4. **確認してほしいこと**（誤りがあれば返信してほしい期限）
5. **次回の予定**（あれば）

詳細は添付に任せ、本文では「ここだけ読めば動ける」状態にします。そしてAIには、議事録の本文を渡して、この5点に整理して文章にしてもらいます。

## コピペ用プロンプト①：社内会議の議事録送付メール

議事録の本文（または箇条書きのメモ）を貼り付けて使います。

```
あなたはビジネスメールの下書きを手伝うアシスタントです。
下の議事録をもとに、会議参加者と関係者に送る「議事録送付メール」を作成してください。

【会議情報】
- 会議名：【例：営業部 週次定例】
- 日時：【例：11月7日 10:00〜11:00】
- 送付先：【参加者／欠席者を含む関係者】
- 送り主：【自分の名前・役割】

【議事録】
【ここに議事録本文またはメモを貼り付け】

【書き方のルール】
- 件名は「【議事録】会議名（月/日開催）」の形にする
- 冒頭は1〜2文。参加のお礼と、議事録を添付した旨だけにする
- 「決定事項」を箇条書きで最大3点にまとめる
- 「各自のタスク」を「担当者／内容／期限」の形で一覧にする。議事録に書かれていない担当や期限は推測せず、「未定」と書く
- 「内容に誤りがあれば○月○日までにご連絡ください」の一文を入れる
- 本文全体は400字以内。長い説明は添付ファイルに任せる
- 欠席者にも状況が伝わるよう、略語や社内用語にはひと言の補足を付ける

件名案を2つ、本文を1パターン出してください。
```

「議事録に書かれていないことは推測しない」という指定が重要です。これを入れないと、AIが気を利かせて期限や担当者を補ってしまうことがあります。

## コピペ用プロンプト②：社外の取引先に送る議事録メール

社外向けは、社内向けより丁寧さと「認識合わせ」の意識が必要です。ここでは、お互いの理解が一致しているかを確認する書き方にします。

```
次の打ち合わせの内容をもとに、取引先に送る議事録送付メールを書いてください。

- 先方：【会社名・部署・氏名】
- 打ち合わせ日時と内容：【日時／議題】
- 合意した事項：【箇条書き】
- 当方が対応すること：【内容と期限】
- 先方にご対応いただくこと：【内容と期限】
- 次回の予定：【日程 or 未定】

ルール：
- 件名は「【議事録】○月○日 △△打ち合わせの件」とする
- 冒頭で打ち合わせのお礼を述べる
- 「合意事項」「当方の対応」「ご対応のお願い」の3つの見出しで整理する
- 「認識に相違がないか、ご確認をお願いします」と、確認の期限を入れる
- 強い言い方を避け、依頼は「〜いただけますと幸いです」の形にする
- 価格・納期などの数字は、私が書いたとおりに転記し、言い換えない
- 全体で500字以内

件名案を2つ、本文を出してください。
```

## 使い方のコツ：議事録を全部貼らなくてもいい

議事録が長い場合は、全文ではなく、**決定事項・TODOの部分だけ**を貼れば十分です。TODOの抜き出しに手間がかかるときは、先に[会議メモからToDoを抽出する方法]({{ site.baseurl }}{% post_url 2026-10-16-ai-kaigi-todo-chushutsu %})で一覧にしてから、このプロンプトに渡すと精度が上がります。

また、同じ会議体では毎回ほぼ同じ形式で送ることになります。一度うまくいった文面は保存しておき、次回は「前回の送付メールと同じ形式で、今回の議事録に書き換えて」と頼むと、さらに短時間で済みます。

## 送る前のチェックリスト

- [ ] 件名で、どの会議かが一目でわかるか（会議名と開催日が入っているか）
- [ ] 決定事項が、議事録の内容と一致しているか
- [ ] 担当者名・期限が正しいか（AIが補ったものがないか）
- [ ] 金額・日付・数量などの数字が、議事録どおりか
- [ ] 宛先（To/Cc）に、欠席者や関係者が含まれているか。社外が混ざっていないか
- [ ] 添付ファイルが最新版か。社外に出せない内部情報が含まれていないか
- [ ] 確認の期限が入っているか

特に、**担当者と期限**はトラブルになりやすい箇所です。AIの出力を鵜呑みにせず、必ず議事録と見比べてください。また、機密性の高い会議の内容をAIに貼る場合は、社内のルールに従い、社名や個人名を伏せ字に置き換えてから使いましょう。

## 送るタイミングの目安

議事録は、**会議当日〜翌営業日中**に送るのが一般的な目安です。時間が経つほど記憶が薄れ、「そんな話だったっけ」というズレが生じやすくなります。完璧な議事録を翌週に送るより、要点だけでも早く共有し、詳細版は後から差し替えるほうが、実務ではうまく回ります。

## まとめ

- 議事録の送付メールは、**ファイルの案内ではなく「決定・依頼・期限」の共有**として書く
- 本文は3点（決定事項／誰がいつまでに何を／確認の期限）に絞り、詳細は添付に任せる
- AIには「議事録にない担当・期限は推測しない」「数字は言い換えない」と明示する
- 送る前に、担当者・期限・宛先・添付を必ず人の目で確認する

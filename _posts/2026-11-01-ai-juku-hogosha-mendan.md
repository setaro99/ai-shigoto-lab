「成績が伸びていない生徒の保護者に、どう伝えればいいか毎回悩む」「授業後の連絡文が、いつも同じ内容になってしまう」「三者面談の前日になって、慌てて話すことを考えている」——学習塾の講師や個人指導をしている方から、よく聞く悩みです。

答案を見る時間や授業を磨く時間は惜しまないのに、**「言葉にする時間」**でつまずく。しかも保護者への伝え方は、その後の信頼関係に直結するので、手を抜けません。

この記事では、保護者への連絡文と三者面談の進行メモを**AIで下書きし、講師が仕上げる**方法を紹介します。ChatGPT・Gemini・Copilot・Claudeのどれでも使える形です。

## 解決の考え方：「事実」「見立て」「次の一手」に分けて渡す

保護者連絡が書きにくい最大の理由は、事実と感想と提案が頭の中で混ざっているからです。AIに頼む前に、メモを次の3つに分けます。

1. **事実**：小テストの点数の推移、宿題の提出状況、授業中の様子など、誰が見ても同じと言えること
2. **講師の見立て**：「計算ミスが多いのは、途中式を省いているためではないか」など、あくまで講師の観察に基づく仮説
3. **次の一手**：塾で行うこと、ご家庭にお願いしたいこと（ひとつかふたつに絞る）

この3つを分けて渡すと、AIは「事実→見立て→提案」の順に整った文章を作ってくれます。保護者は「何があって、先生はどう見ていて、何をすればいいのか」が一目で分かります。

もうひとつのコツは、**「良いこと」から書き始めてもらう**ことです。伸び悩みを伝える連絡でも、まず具体的な取り組みの良い点を一文入れるだけで、受け取られ方は大きく変わります。ただし、ほめる材料がないのに無理にほめる必要はありません。その場合は「宿題の提出は毎回できています」のような事実で十分です。

## コピペで使えるプロンプト

【 】を実際の内容に書き換えて貼り付けてください。生徒の氏名は入れず「生徒」「お子さま」のままにします。

### ① 授業後の保護者連絡文を作る

```
あなたは学習塾の講師の文章作成を手伝うアシスタントです。
次のメモから、保護者へ送る連絡文（300字程度）を作ってください。

【事実】
・【例：直近2回の小テストは、60点→55点】
・【例：宿題は毎回提出できている】
【私の見立て】
・【例：途中式を省くため、計算ミスが増えているように見える】
【次の一手】
・塾で：【例：授業内で途中式を書く練習を5分入れる】
・ご家庭で：【例：宿題の直しを、1問だけ声に出して説明してもらう】

【条件】
・最初に、事実としての取り組みの良い点を一文入れる
・点数の低下は、責める調子にならず事実として伝える
・見立ては「〜のように見えます」と断定を避ける
・成績が上がると約束するような表現は使わない
・最後はご家庭への負担にならない一言で結ぶ
・「いつもお世話になっております」で始め、敬語は丁寧に
```

### ② 三者面談の進行メモ（15分）を作る

```
学習塾の三者面談（15分）の進行メモを作ってください。

【状況】
・学年：【例：中学2年】　教科：【例：数学】
・現状（事実）：【例：定期テストは平均前後。宿題の提出は良好】
・講師が伝えたいこと：【例：計算の正確さを上げる練習が必要】
・保護者が気にしていそうなこと（予想）：【例：部活との両立、受験までの見通し】

【出力形式】
1. 時間配分つきの流れ（冒頭の挨拶／近況／課題／今後の進め方／質問タイム）
2. 最初に保護者に聞く質問を3つ（家庭での様子を聞き出すもの）
3. 課題を伝えるときの言い方の例（責めない言い回し）
4. 想定される質問と、答えのたたき台（志望校の合否や成績向上の見込みを断定する回答は作らない。その場合は「現時点の事実と、今後の取り組み」で答える形にする）
5. 面談の最後に確認することのチェックリスト
```

「家庭での様子を聞く質問」を先に置くのが、面談を一方通行にしないコツです。

### ③ 面談後のお礼とまとめの連絡文

```
三者面談の後に保護者へ送るお礼とまとめの連絡文（250字程度）を作ってください。

【面談で話したこと】
・【例：計算ミスを減らすため、授業内で途中式の練習を行う】
・【例：ご家庭では宿題の直しを1問説明してもらう】
【保護者のご要望・ご心配】
・【例：部活が忙しい時期の宿題量を心配されていた】

【条件】
・面談の時間を取っていただいたお礼から始める
・決めたことを2点に絞って箇条書きにする
・ご要望には「確認のうえ対応を検討します」の形で受け止め、実現を約束しない
・次回の連絡時期を一言入れる
```

### ④ 伸び悩み生徒への声かけ案（生徒本人向け）

```
中学生の生徒への声かけ案を3パターン作ってください。

状況：【例：小テストの点が2回続けて下がり、本人が落ち込んでいる】
目的：【例：次の小テストに向けて、小さな目標を一緒に決める】

条件：
・叱る・比べる言い方は使わない
・具体的な行動（「今日は3問だけ」など）に落とし込む
・1パターン50字以内
```

## 送る前のチェック

- **氏名・成績の詳細はAIに入れない**：生徒や保護者の個人情報、具体的な点数や順位の細かな数字は、一般化して入力します（例：「60点台」「平均前後」）。実際の数字や名前は、出力した文章に講師自身が書き足します
- **進路・志望校・合否の判断はAIに任せない**：文章に「合格できます」「この点数なら大丈夫です」といった断定が入っていたら削ります。見立ては、講師自身の観察に基づく範囲にとどめます
- **成績が上がる約束をしない**：「必ず伸びます」は、結果が伴わなかったときの信頼を損ないます。「取り組みます」「様子を見ながら調整します」の形が安全です
- **料金・契約・規程に関わる内容は塾の方針に従う**：コース変更や追加授業の案内など、AIが作った言い回しをそのまま使わず、塾の規程と照らし合わせます
- **声に出して読み、その生徒の保護者に合う温度か確かめる**：丁寧すぎる、冷たい、馴れ馴れしい——この微調整だけは、日頃の関係を知る講師にしかできません

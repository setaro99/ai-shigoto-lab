「納期や提出期限の管理表で、期限を過ぎた行だけ目立たせたい」「未入力のセルに色が付けば、確認漏れが減るのに」——そう思いながら、毎回目視で探している方は多いのではないでしょうか。

これを自動でやってくれるのが、Excelの**条件付き書式**です。ただ、「ルールの管理」「数式を使用して…」といった画面が分かりにくく、数式も書き方にコツがあるため、途中で諦める人が少なくありません。この記事では、**やりたいことを日本語で伝えてAIに設定手順と数式を作ってもらう方法**を紹介します。

## つまずくのは「ルールの作り方」ではなく「伝え方」

条件付き書式の仕組み自体はシンプルです。

> 「この条件に当てはまるセル（または行）に、この色を付ける」

つまずきやすいのは、次の3点です。

1. **セル単位か、行全体か**——期限のセルだけ赤くするのか、その行をまるごと色付けするのかで、設定方法が変わる
2. **条件を数式で書く場面がある**——「期限が今日より前、かつ完了欄が空欄」のような複数条件は、数式で指定する
3. **適用範囲と式の「$」**——行全体に色を付けるとき、列の固定（`$C2` のような書き方）を間違えると、色が付く場所がずれる

AIに頼むと、この3点を自分の表の状況に合わせて整理した形で教えてもらえます。そのためには、**表の構造を具体的に伝える**ことが何より大切です。

## 伝えるべき情報は5つだけ

AIに渡す材料は、次の5つです。

| 伝える内容 | 例 |
|---|---|
| 環境 | Windows／Mac、Microsoft 365など |
| 表の列構成 | A列=案件名、C列=期限、D列=完了（〇が入る） |
| データの範囲 | 2行目から200行目まで |
| 色を付けたい条件 | 期限が今日より前で、完了欄が空欄の行 |
| 付けたい色と範囲 | 行全体を薄い赤に、など |

「期限切れを赤くしたい」とだけ頼むと、AIは前提を推測して答えます。完了済みの案件まで赤くなるなど、意図と違う結果になりがちです。**どの列に何が入っているか**を書くのが近道です。

## コピペで使えるプロンプト①：条件付き書式の設定手順と数式を作る

【 】の中を書き換えて、ChatGPT・Copilot・Gemini・Claudeなど使い慣れたAIに貼り付けてください。

```
あなたはExcelに詳しい事務サポート担当です。
条件付き書式で、次の条件に当てはまる行に色を付けたいです。設定手順と数式を教えてください。

【使っている環境】【例: Windows11 / Microsoft 365のExcel】
【表の構成】【例: 1行目が見出し。A列=案件名、B列=担当者、C列=期限（日付）、D列=完了（終わったら「〇」を入力）】
【データの範囲】【例: 2行目〜200行目、A列〜D列】
【色を付けたい条件】【例: 期限が今日より前で、D列が空欄の行】
【付けたい色と範囲】【例: 行全体（A〜D列）を薄い赤】

条件:
・「ホーム」タブからの操作を、番号付きの手順で書く（バージョンで名称が違う場合は、その旨も書く）
・「数式を使用して、書式設定するセルを決定」で入れる数式を、そのままコピーできる形で示す
・数式の中の「$」の意味を、初心者向けに2〜3行で説明する
・「適用先」に入れる範囲も明記する
```

返ってきた数式は、たとえば「`=AND($C2<TODAY(),$D2="")`」のような形になります。**「$C2」と、列だけ固定して行は固定しない**のが、行全体を色付けするときの基本形です。

## コピペで使えるプロンプト②：複数のルールを整理する

期限管理では、色を使い分けたくなる場面があります。「期限切れは赤」「3日以内は黄色」「完了済みは灰色」のように複数のルールを置くと、**どれを優先するか**を決める必要があります。

```
Excelの条件付き書式で、次の3つのルールを組み合わせたいです。
ルールの順序（優先順位）と、それぞれの数式を教えてください。

【表の構成】【例: C列=期限、D列=完了（〇が入る）、2〜200行目、A〜D列に適用】
【ルール】
1. 完了済み（D列が「〇」）の行は、文字を灰色にする
2. 期限が今日より前で未完了の行は、薄い赤にする
3. 期限が今日から3日以内で未完了の行は、薄い黄色にする

条件:
・ルールの管理画面で、上から何番目に置くべきかを理由つきで説明する
・「条件を満たす場合は停止」の使いどころを説明する
・ルール同士が衝突して意図しない色になるケースがあれば、先に注意として書く
```

ルールは**上にあるものが優先**されます。「完了済み」のルールを一番上に置いて「条件を満たす場合は停止」を使えば、完了済みの行が赤や黄色に染まる事態を避けられます。

## コピペで使えるプロンプト③：思った通りに色が付かないとき

設定したのに色が付かない、関係ない行まで色が付く。そんなときは、現状をそのままAIに見せて原因を探します。

```
Excelの条件付き書式を設定しましたが、意図どおりに色が付きません。原因の候補を可能性が高い順に挙げ、確認方法と直し方を教えてください。

【やりたいこと】【例: 期限が過ぎていて、D列が空欄の行だけ赤にしたい】
【設定した数式】【例: =AND(C2<TODAY(),D2="")】
【適用先】【例: =$A$2:$D$200】
【実際に起きていること】【例: 完了済みの行まで赤くなる／2行目だけ色が付く／まったく色が付かない】
【C列の中身の例】【例: 2026/10/20、10月20日、20-Oct のように表記がまちまち】

条件:
・数式の「$」の位置、日付が文字列になっている可能性、適用先の範囲のずれを必ず確認する
・直し方は、画面の操作で順番に書く
```

意外に多い原因が、**日付に見えて実は文字列になっているセル**です。この場合は大小比較がうまく働かず、色が付きません。セルを左揃えにしたとき左に寄る、あるいは書式を「標準」にして数字（シリアル値）に変わらない場合は、文字列の疑いがあります。

## 設定したあとの4つのチェック

1. **テストデータで試す**——期限が昨日・今日・3日後・空欄のサンプル行を1〜2行作り、意図した色になるか確かめる。本番の表に入れる前に確認すると安全です
2. **行を追加・削除したあとの適用範囲を確認する**——行を足したり消したりすると、適用先が分割されることがある。ときどき「ルールの管理」を開いて範囲をチェックする
3. **「今日」の基準を理解する**——`TODAY()` はファイルを開くたびに更新される。過去の時点の状態を残したい資料では、色付けに頼らず、別途メモや印刷で記録する
4. **色だけに頼らない**——白黒印刷や色の見え方に個人差がある場合に備え、重要な表では「期限切れ」といった文字の列も併用する。また、実データ（顧客名など）をAIに貼らず、列の構成だけを伝えれば十分です

## まとめ

条件付き書式は、**「どの列に何が入っていて、どの条件のとき、どこに色を付けたいか」**を日本語で説明できれば、設定手順と数式はAIが作ってくれます。ポイントは、表の構造を具体的に伝えること、複数のルールは優先順位を決めること、設定後は必ずテスト行で動作を確認することです。

期限管理を目視から仕組みに替えるだけで、確認の手間と見落としの不安はずいぶん減ります。まずは自分の管理表で、いちばん見落としたくない条件を1つだけ色付けしてみてください。

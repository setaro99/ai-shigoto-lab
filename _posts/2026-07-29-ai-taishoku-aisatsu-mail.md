「退職が決まった。最後にお世話になった人たちへ挨拶メールを送らなければ」——このとき、多くの人が思った以上に手が止まります。長く働いた会社ほど、感謝の言葉が多すぎても少なすぎても違和感が出ますし、社内向けと取引先向けで書き分けなければいけないことに気づいて、余計に時間がかかるからです。

この記事では、退職の挨拶メールをAIで、社内・社外それぞれにふさわしいトーンで素早く書く方法を、コピペで使えるプロンプト付きで紹介します。

## 退職の挨拶メールが難しい理由は「相手ごとの温度差」

退職の挨拶メールで悩む人の多くは、次のどちらかでつまずいています。

・社内向けと取引先向けを同じ文面で済ませようとして、どちらにも中途半端になる
・退職理由やこれまでの不満をつい書きたくなり、筆が止まる

退職理由は基本的に書く必要がありません。「一身上の都合により」で十分であり、それ以上の説明は求められていないことがほとんどです。書くべきは「感謝」と「今後への配慮」の2つだけ。この軸さえ決まれば、AIに任せて数十秒で下書きが仕上がります。

## 送る相手で変える「型」を先に押さえる

具体的なプロンプトの前に、相手別の構成を整理しておきます。

**社内向け（同僚・上司・部下宛の一斉送信）**

1. **退職日の報告** — いつ付けで退職するかを最初に明記
2. **在籍中の感謝** — 部署名やプロジェクト名を挙げると温かみが出る（挙げすぎない）
3. **今後の連絡先（任意）** — 個人の連絡先を伝えたい場合のみ、一文で
4. **結びの挨拶** — 相手の活躍を願う一文

**取引先向け（担当者宛の個別送信）**

1. **退職日の報告とこれまでの感謝**
2. **後任者の紹介** — 氏名・部署・引き継ぎ状況を明確に
3. **引き継ぎ完了の見通し** — 「〇月〇日までに正式にご案内します」など
4. **今後も変わらぬお付き合いのお願い**

社内向けは温かみとカジュアルさを、取引先向けは丁寧さと「業務が滞らない」という安心感を優先するのがポイントです。

## コピペで使えるプロンプト（社内向け）

以下をAIに貼り付け、【 】の中だけをあなたの状況に書き換えてください。ChatGPT・Copilot・Gemini・Claude、どれでも動きます。

```
あなたは日本企業の慣習に詳しいビジネスメールの専門家です。
退職する社員が社内の同僚・関係者へ送る挨拶メールを書いてください。

・退職日: 【2026年9月30日】
・所属期間・部署: 【営業部に7年間在籍】
・宛先: 【社内の同僚・関係者全員（一斉送信）】
・伝えたいこと: 【多くの人に支えられて働けたことへの感謝】
・個人の連絡先を伝えるか: 【伝えない】

条件:
・退職理由には触れない
・「退職日の報告→在籍中の感謝→結びの挨拶」の順で
・堅すぎず、温かみのある文体で250字前後
・件名も1案つける
```

## コピペで使えるプロンプト（取引先向け）

取引先には、感謝に加えて「業務が滞らない」という安心感を伝えることが欠かせません。

```
あなたはBtoB取引に強いビジネスメールの専門家です。
退職する担当者が取引先へ送る挨拶メールを書いてください。

・退職日: 【2026年9月30日】
・これまでの取引関係: 【3年間、〇〇社様の窓口を担当】
・後任者: 【同部署の△△、氏名と連絡先は後日正式に案内予定】
・引き継ぎ状況: 【今月末までに担当変更のご案内を別途送付】

条件:
・退職理由には触れない
・「感謝→後任者の紹介→引き継ぎの見通し→今後のお願い」の順で
・丁寧だが事務的になりすぎない文体で300字前後
・件名も1案つける
```

## 送信前に必ず確認する3点

AIが作った文面はそのまま使えることが多いですが、送信前に次の3点は自分の目で必ず確認してください。

・**会社のルールに沿っているか** — 退職の社外公表タイミングや、一斉送信の可否は会社によって異なります。上長や総務に確認してから送るべき内容が含まれていないか見直しましょう
・**後任者情報が正確か** — 取引先向けメールでは、後任者の氏名・部署・引き継ぎ完了時期にズレがあると相手を混乱させます。送信前に後任者本人にも文面を確認してもらうと安心です
・**ネガティブな表現が残っていないか** — AIが生成した文面に、退職理由や会社への不満につながる言葉が紛れていないか。円満な印象で終える文章になっているかを最後に読み返しましょう

## まとめ

退職の挨拶メールは、感謝と配慮さえ押さえれば、社内向け・取引先向けのどちらもAIが数十秒で下書きしてくれます。あなたがやるべきことは、ゼロから言葉を考えることではなく、会社のルールと後任者情報を確認し、最後にネガティブな表現が残っていないかをチェックするだけです。これだけで、気の重い最後のメール作業が短時間で終わります。

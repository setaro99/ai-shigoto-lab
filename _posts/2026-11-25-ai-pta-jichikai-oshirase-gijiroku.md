「今年、役員が回ってきました」。PTA、自治会（町内会）、マンションの管理組合。仕事とは別に、持ち回りで役員を引き受けた途端、お知らせ文や議事録の作成が自分の仕事になります。

しかも、書き方を教えてくれる人はいません。前年度のファイルは日付だけが違う1枚。回覧板の文面は「協力のお願いが押し付けに聞こえないか」と気になって、何度も書き直してしまいます。会議のあとの議事録づくりで、夜が潰れる方も多いはずです。

この記事では、**お知らせ文**と**議事録**の下書きをAIに任せる方法を紹介します。ChatGPT・Copilot・Gemini・Claudeのどれでも使える形にしています。

## 役員の文章仕事が重くなる理由

文章が苦手だから大変、というわけではありません。つまずく原因は別にあります。

・**読む相手の幅が広い**：小学生の保護者から高齢の住民まで、同じ1枚を読みます。難しい言い回しも、くだけすぎた言い方も気になります
・**お願いの言葉に気を遣う**：参加や当番をお願いする文面は、強すぎても弱すぎても角が立ちます
・**決まったことが記録に残らない**：会議中に走り書きしたメモが、数日後には自分でも読めなくなります
・**頼れる前例が少ない**：引き継ぎがあっても、様式は年度ごとにばらばらです

つまり必要なのは、うまい文章より「**伝える項目の整理**」と「**言い回しの調整**」です。この2つは、AIが最も得意とする作業です。

## 解決の考え方：決まっていることだけを渡す

AIに頼む前に、次の4つをメモします。箇条書きで十分です。

1. **日時・場所・集合時間**：決まっている分だけ。未定の項目は「未定」と書きます
2. **対象と人数**：「1〜6年生の保護者」「A棟の全世帯」など
3. **お願いしたいこと**：参加、当番、持ち物、返信の期限
4. **問い合わせ先の役割名**：「会長」「広報担当」など。電話番号や個人名は、AIには入力せず、配る直前に自分で書き足します

**日時・金額・規約の内容などの事実は、必ず人が決めて人が確かめます。** AIには、それを読みやすく並べる作業を頼みます。ここの線引きが、一番大切です。

## コピペ用プロンプト①：お知らせ文を作る

【】の中を自分の状況に合わせて書き換えてください。

```
あなたは地域団体の広報担当のアシスタントです。
保護者・住民向けのお知らせ文を作ってください。

【団体】【小学校のPTA／〇〇町内会／マンション管理組合】
【お知らせの内容】【12月の資源回収への協力のお願い】
【日時】【12月14日（日）8:30〜10:00】※雨天時は【中止か順延かを後日連絡】
【場所】【校庭の北側】
【対象】【全世帯】
【お願いしたいこと】【資源を前日までにまとめる／当日の手伝いを数名募集】
【返信の期限】【12月5日】
【問い合わせ先】【広報担当（連絡先は後で自分で記入）】

条件:
- 本文は300字前後、読み手が初めてでも分かる言葉で
- 「お願い」の調子にし、強制に聞こえる表現は避ける
- 日時・場所・期限は本文の冒頭に箇条書きでまとめる
- 私が渡していない情報（金額、規約、罰則、電話番号など）は書かず、必要なら【要確認】と書いて空欄にする
- 件名（またはタイトル）を3案
- 最後に、読み手から出そうな質問を3つ挙げる
```

最後の「出そうな質問」が役に立ちます。「雨だったらどうなるの？」「手伝えない家庭は？」といった問い合わせを、配る前に先回りして書き足せます。

## コピペ用プロンプト②：協力のお願いを角の立たない言い方にする

すでに自分で書いた文面があるときは、整える形で頼みます。

```
次のお知らせ文を、協力をお願いする調子に書き直してください。
内容や数字、日時は変えないでください。

【自分で書いた文面を貼る】

条件:
- 「〜してください」の連続を避け、理由を一言添える
- 参加できない場合の選択肢（欠席の連絡方法など）が書かれていれば残し、無ければ【要確認】として一行足す
- 変更した箇所を、元の文と並べて一覧にする
```

**変更箇所の一覧**を出させておけば、AIが日時や数字を勝手に直していないかを一目で確認できます。

## コピペ用プロンプト③：会議のメモから議事録を作る

会議の最中は、細かくなくて構いません。走り書きのメモを、あとからこう渡します。

```
次の会議メモから、役員会の議事録を作ってください。

【会議名】【第〇回 役員会】
【日時】【　】
【出席】【〇名（個人名は書かない）】
【メモ】
【ここに走り書きのメモを貼る】

出力の形式:
1. 決まったこと（箇条書き）
2. 決まっていないこと・次回に持ち越すこと
3. 担当と期限（表形式。担当は「会計担当」など役割名で）
4. 次回の日程

条件:
- メモに書かれていないことは補わない
- 意味が取れない箇所は、推測せず【確認】として残す
- 全体で500字以内
```

「決まっていないこと」を分けて書かせるのがコツです。議事録に曖昧な記述が混ざると、数か月後に「そんなことを決めただろうか」という行き違いのもとになります。

## 配る前のチェック

お知らせも議事録も、出す前に次の点を確かめてください。

□ **日時・場所・期限は、決定事項と一致しているか**：AIが曜日や時刻を言い換えて、ずれることがあります
□ **規約・会則の内容を、AIの文面が断定していないか**：会則の解釈や総会の成立要件、会計・税務に関わる説明は、AIに任せません。分からない点は、団体の規約や担当の先生・管理会社に確かめてください
□ **個人情報が入っていないか**：会員や住民の氏名、住所、連絡先は、AIに入力しません。学校や団体にAIの利用ルールがあれば、それに従います
□ **お願いが強制に読めないか**：参加できない人への配慮の一行があると、読み手の印象が大きく変わります
□ **別の誰かの目を通したか**：会長や副会長に一度目を通してもらってから配ると、後の訂正連絡が減ります

AIが作るのは下書きです。「あの家庭は今年、事情があって負担が大きい」といった地域の事情は、役員の方にしか分かりません。最後は自分の言葉で一度読み直してください。

## まとめ

・先に渡すのは、決まっている日時・対象・お願いの内容。連絡先や個人名は渡さない
・お知らせ文は「冒頭に要点を箇条書き」と「出そうな質問」を一緒に頼む
・自分で書いた文面は、変更箇所の一覧つきで整えてもらう
・議事録は「決まったこと」と「決まっていないこと」を分けて書かせる
・事実と規約は、人が確かめる

役員の任期は、短く区切られています。毎年の担当者がゼロから悩まずに済むよう、今年のお知らせ文と議事録を、来年の方への置き土産として残してみてください。

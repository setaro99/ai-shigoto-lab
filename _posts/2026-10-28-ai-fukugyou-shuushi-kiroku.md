「副業を始めたものの、収支の記録が溜まっていく」——スマホのメモに入金額、財布にレシート、銀行アプリに振込履歴。月末に見返すと、何がいくらの売上で、何が仕事の出費だったのか思い出せない、という悩みは珍しくありません。

記録が続かない最大の理由は、書式が人によってバラバラな「素材」を、あとからひとつの表に揃える作業が面倒だからです。この**「揃える作業」**はAIが得意な分野です。この記事では、雑なメモを収支の表に整えるプロンプトと、AIに任せない線引きを紹介します。

なお、何が経費になるか、いくら申告すべきかといった**税務の判断はこの記事では扱いません**。迷う点は、税務署の案内や税理士など専門家に確認してください。

## 解決の考え方：「判断」ではなく「整形」を頼む

AIに頼むのは、次の2つに限ります。

- **整形**：バラバラな書き方のメモを、同じ列（日付・内容・金額・収入/支出）の表にそろえる
- **確認の補助**：日付の抜け、金額の桁違い、同じ入力の重複など「怪しい行」に印をつける

頼まないのは次の部分です。

- 経費として認められるかどうかの判断
- 税額や申告方法の判断

分類の列には、AIに「仮」と付けた区分案を出させ、**最終的な決定は自分で行う**。これが事故の少ない使い方です。

## 事前に決めておく「列」

表の列は最初に固定します。迷ったらこの6列で十分です。

1. 日付（YYYY/MM/DD）
2. 取引先・相手（案件名でも可）
3. 内容（何の売上か、何の支払いか）
4. 収入額
5. 支出額
6. 区分（仮）：例「売上」「交通費」「通信費」「消耗品」「その他」

自分の区分名があるなら、それをAIに先に渡すと、毎回同じ名前でそろいます。

## コピペで使えるプロンプト

ChatGPT・Copilot・Gemini・Claudeのどれでも使えます。【 】の部分を書き換えてください。

```
あなたは丁寧な帳簿の整理アシスタントです。
下の「雑なメモ」を、収支記録の表に整えてください。

【メモ】
【ここに入金メモ・レシートの文字・支払いの記録をそのまま貼る】

条件:
・列は「日付 / 取引先 / 内容 / 収入額 / 支出額 / 区分（仮）」の6列
・日付は YYYY/MM/DD に統一。年が不明なものは【今年の西暦】年として扱い、末尾に「年を補った」と書く
・金額は半角数字、カンマなし。収入と支出は別の列に分ける
・区分（仮）は次の候補から選ぶ: 売上 / 交通費 / 通信費 / 消耗品 / 外注費 / その他
・読み取れない項目は推測で埋めず、「要確認」と書く
・経費として認められるかどうか、税務上の判断は一切しない
・最後に「確認が必要な行」を番号付きで列挙する（日付が不明、金額が不自然、重複の可能性など）
```

出力は表形式で返ってきます。表をコピーして表計算ソフトに貼れば、そのまま集計の土台になります。

### 月の終わりに使う「見直し用」プロンプト

整えた表が溜まったら、月末にこちらを使います。

```
下の収支記録の表を読んで、次の3点を確認してください。
1. 日付の抜け・重複の可能性がある行
2. 金額が他の行と比べて極端に大きい／小さい行
3. 区分が「その他」になっている行の一覧

[ここに表を貼る]

注意: 経費にできるかどうかの判断や、税額の計算はしないでください。
気づいた点だけを箇条書きで返してください。
```

## 使う前のチェック

実際に使う前に、次の点を確認してください。

- **個人情報・口座情報は伏せる**：口座番号、カード番号、取引先の実名や住所は、貼る前に消すか「A社」に置き換えます。金額と日付の整形だけならこれで十分です
- **金額は必ず元の記録と見比べる**：AIは桁を読み違えることがあります。特に高額の行は、レシートや通帳の元データと照合します
- **合計は自分でも計算する**：AIの合計は参考値にとどめ、表計算ソフトの合計とあわせて確認します
- **「要確認」を放置しない**：AIが空欄にした行は、後回しにすると思い出せなくなります。その日のうちに元の記録を見て埋めます
- **区分は仮のまま確定しない**：区分の列はあくまで下書きです。判断に迷うものは、公的な案内か専門家に確認します

## 続けるための小さな工夫

- **週1回、5分だけ貼る**：溜めるほど整形の量が増えます。日曜の夜などに、1週間分のメモをまとめてAIに渡すだけで十分です
- **使った指示文を保存する**：区分の候補や列の指定を含むプロンプトを1つのメモに保存しておけば、毎回コピペで済みます
- **元の記録は捨てない**：レシートや通帳のコピーなど、元データは別に保管しておきます。AIの表はあくまで「見やすく整えた写し」です

## まとめ

副業の収支記録が続かないのは、記録そのものより「バラバラな素材を揃える作業」が重いからです。ここをAIに任せ、日付・金額・区分の列で表にそろえれば、週5分ほどの作業で記録が溜まらなくなります。一方で、経費の可否や税額の判断はAIに任せず、元データとの照合は自分で行う。この線引きを守れば、AIは頼れる帳簿の下ごしらえ係になります。

「取引先の担当者が部長に昇進したと聞いた」「お世話になった方が独立して店を開くらしい」——うれしい知らせを聞いたとき、お祝いのメールを送りたいと思っても、意外と手が止まります。

失礼があってはいけない。かといって「ご昇進おめでとうございます。ますますのご活躍をお祈りします」だけでは、誰にでも送れる定型文のようで味気ない。結局、送るタイミングを逃して「もう時期を過ぎたかも」と見送ってしまった、という経験はないでしょうか。

この記事では、AIにお祝いメールの下書きを作らせる方法を、**「ひと言の具体性」を足す材料の揃え方**を中心に紹介します。

## お祝いメールが「定型文」になってしまう3つの理由

1. **書く材料が「おめでとう」しかない**——相手との関係や思い出を言葉にしていないので、どの相手にも同じ文面になる
2. **敬語と祝意の言葉選びに自信がない**——「ご昇進」「ご就任」「ご栄転」の使い分けや、避けたほうがよい言葉が分からない
3. **タイミングを気にして先延ばしにする**——知らせを聞いてから時間が空くほど、送りづらくなる

解決のカギは、文章の上手さではなく、**相手について自分が知っていること**を3つ書き出してからAIに渡すことです。

## 解決の考え方：祝意に「事実」を1つ添える

お祝いの文面で印象に残るのは、立派な美辞麗句よりも、**自分との具体的なつながり**です。次の材料を、箇条書きで構いませんのでメモしてください。

| 材料 | 例 |
|---|---|
| ①何のお祝いか | 部長へのご昇進、新店舗のオープン、社内表彰の受賞など |
| ②相手との関係 | 取引先の担当者／他部署の先輩／元同僚 |
| ③自分が知っている事実 | 昨年の展示会で資料を何度も直してくれた、いつも納期を守ってくれた |
| ④お祝いの気持ちの根拠 | 「あの丁寧な仕事ぶりなら当然だと思った」など自分の感想 |
| ⑤今後の関わり | 引き続き担当を続ける、近々お会いする予定がある、など |
| ⑥送る手段と形式 | 社内チャット、取引先へのメール、手書きのカードに添える文面など |

とくに③と④が大切です。これを一文入れるだけで、「自分に向けて書いてくれたメールだ」と伝わります。

なお、ここに挙げる事実は**自分が本当に知っていること**だけにしてください。AIは親切心から、それらしいエピソードを作ってしまうことがあります。次のプロンプトでは、その防止も指示に入れています。

## コピペ用プロンプト①：昇進・就任のお祝いメール

【 】の中を書き換えて、ChatGPT・Copilot・Gemini・Claudeなど使い慣れたAIに貼り付けてください。

```
あなたはビジネスマナーに詳しい、気配りのある書き手です。
昇進・就任のお祝いメールの下書きを作ってください。

【自社名・部署・私の名前】【例: 株式会社サンプル 営業部 山田】
【宛先】【例: ○○商事 営業部 佐藤様】
【お祝いの内容】【例: 営業部長へのご昇進】
【相手との関係】【例: 3年前から担当としてやり取りがある取引先】
【自分が知っている事実】【例: 昨年の新商品の導入時に、社内調整を一緒に進めてもらった】
【自分の感想】【例: いつも先回りして動いてくださり、助けられた】
【今後について】【例: 来月、年末のご挨拶に伺う予定】

条件:
・件名は「ご昇進のお祝い（社名・氏名）」の形で、3案出す
・本文は、挨拶→お祝いの言葉→具体的なエピソード→今後の関係→結びの順にする
・「ご昇進」など相手の立場に合った敬語を使い、へりくだりすぎない
・私が書いていないエピソードや肩書き、人柄は勝手に作らず、不足があれば【要確認】と書く
・お祝いの席への出席依頼や、仕事の依頼は盛り込まない
・250字〜350字程度に収める
```

最後から2つ目の条件も重要です。お祝いメールに商談や依頼を混ぜると、祝意が薄れて打算的に見えてしまいます。**お祝いは、お祝いだけで完結させる**のが基本です。

## コピペ用プロンプト②：開業・独立のお祝いメール

独立や開業は、昇進に比べて**相手の不安と期待が大きい**場面です。励ます姿勢を入れたいところですが、上から目線になりやすい点には注意が必要です。

```
独立・開業のお祝いメールを書いてください。

【相手】【例: 元同僚の高橋さん（友人に近い関係）】
【お祝いの内容】【例: 飲食店の開業】
【自分が知っている事実】【例: 同じ部署で3年一緒に働いた。いつか自分の店を持ちたいと話していた】
【オープン日・場所が分かっていれば】【例: 12月1日、駅前】
【こちらから伝えたいこと】【例: 開店したら、同僚を誘って行きたい】

条件:
・相手との距離感に合わせ、ですます調で、堅すぎないトーンにする
・「応援しています」だけで終わらせず、自分がするつもりの具体的な行動（行く・紹介する等）を一文入れる
・「成功間違いなし」「儲かりますね」のような断定や、金銭に触れる言葉は使わない
・相手が忙しい時期なので、返信は不要という一文を添える
・200字〜300字程度に収める
```

「返信不要」と添えるのは、地味ですが効果的な気遣いです。開業前後の相手は準備に追われているため、返信という負担をかけない配慮が伝わります。

## コピペ用プロンプト③：お祝いへのお礼（返信）を書く

逆に、自分がお祝いのメールをもらったときの返信にも使えます。

```
昇進のお祝いメールをいただいた方への、お礼の返信を書いてください。

【相手】【例: ○○商事 佐藤様】
【いただいた言葉の要点】【例: 昨年の導入時の協力に触れて祝ってくださった】
【今後の抱負】【例: 引き続き現場の声を大切にしたい】

条件:
・まずお礼、次に相手のメールの一部に具体的に触れる、最後に今後への一言、の順にする
・自分を大きく見せる表現や、謙遜しすぎる表現は避ける
・150字〜220字程度に収める
```

お祝いメールは、受け取った側も返信に迷うものです。「ありがとうございます」だけで返すより、**相手が書いてくれた内容に一言触れる**だけで丁寧な印象になります。

## 送る前に確認する4つのチェック

AIの下書きは、そのまま送らずに次の4点を見てください。

1. **名前・肩書き・社名が正しいか**——人事異動や社名変更の直後は、旧肩書きのままになりやすいので、公式の発表を確認する
2. **事実でないエピソードが混ざっていないか**——「いつも」「何度も」のような頻度の言葉も、実際と合っているかを確認する
3. **避けたい言葉が入っていないか**——「落ちる」「去る」「倒れる」など縁起を連想させる表現や、「ようやく」「やっと」のような上から目線に聞こえる言葉はないか
4. **公表されている情報かどうか**——昇進や異動は、本人が公表する前に第三者が触れると失礼になることがあります。正式な発表のあとに送るのが安全です

会社ごとに、取引先への贈答やお祝い金のルールが決まっている場合があります。金品を添える場合は、必ず自社の規程や上司の判断を確認してください。この記事は文面づくりの方法であり、贈答や契約に関する助言ではありません。

## まとめ

- お祝いメールが定型文になるのは、**自分と相手のつながりを言葉にしていない**から
- ①お祝いの内容 ②関係 ③知っている事実 ④自分の感想 ⑤今後 ⑥送る形式の6つを揃えてからAIに渡す
- 「書いていないエピソードは作らず【要確認】と書く」と指示すると、事実でない話の混入を防げる
- お祝いは依頼や商談と混ぜず、相手の負担になる返信は求めない
- 知らせを聞いたら、完璧を目指さず早めに送るのがいちばんの気遣い

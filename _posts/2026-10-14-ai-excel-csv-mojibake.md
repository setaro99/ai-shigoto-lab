「取引先から届いたCSVをダブルクリックで開いたら、日本語が『縺ゅ＞縺…』のような記号だらけになった」「郵便番号が『0123456』から『123456』に変わっていた」「電話番号が『9.01E+09』になった」——CSVを扱う事務の仕事で、よく出会うトラブルです。

原因は、ファイルが壊れているのではなく、**Excelが「開くときの読み取り方」を自動で決めてしまう**ことにあります。この記事では、症状から原因を切り分ける考え方と、AIに手順を聞いて直すためのプロンプトを紹介します。

## 症状ごとの原因は、ほぼ3つに絞れる

| 症状 | 主な原因 |
|---|---|
| 日本語が意味不明な記号になる | 文字コードの食い違い（UTF-8のファイルをExcelがShift_JISとして読んでいる、など） |
| 先頭の0が消える（郵便番号・社員番号・電話番号） | Excelが「数値」と判断して0を落としている |
| 「9.01E+09」「2024/1/5」に変わる | 長い数字が指数表示に、「1-5」のような文字が日付に自動変換されている |

どれも「Excelが親切のつもりで自動変換している」ことが共通点です。したがって、**ダブルクリックで開かず、読み込み時に列ごとの形式を指定する**のが基本の対処になります。

## 解決の考え方：「開く」ではなく「取り込む」

Excelには、CSVを外部データとして取り込む機能があります（「データ」タブの「テキストまたはCSVから」など。名称や場所はバージョンで異なります）。この方法なら、次の2つを自分で指定できます。

1. **ファイルの文字コード**——文字化けしたら、UTF-8とShift_JIS（日本語Windows標準）を切り替えて、読めるほうを選ぶ
2. **列のデータ形式**——郵便番号や電話番号の列は「テキスト」を指定すれば、0が消えない

ただし、手順の画面名はExcelのバージョンやMac／Windowsで違います。そこで、**自分の環境と症状を伝えてAIに手順を聞く**のが早道です。

ここで大切なのは、**元のCSVファイルを上書き保存しない**ことです。一度Excelで開いて保存すると、消えた0は戻りません。作業前にコピーを取っておきましょう。

## コピペで使えるプロンプト①：症状から原因と手順を聞く

【 】の中を書き換えて、ChatGPT・Copilot・Gemini・Claudeなど使い慣れたAIに貼り付けてください。

```
あなたはExcelに詳しい事務サポート担当です。
CSVファイルをExcelで開いたら困ったことが起きました。原因の候補と、直す手順を教えてください。

【使っている環境】【例: Windows11 / Microsoft 365のExcel】
【困っている症状】【例: 日本語が文字化けする／郵便番号の先頭の0が消える／電話番号が9.01E+09になる】
【CSVの出どころ】【例: 取引先からメールで届いた／基幹システムからダウンロードした】
【列の例（個人情報は架空の値に置き換える）】【例: 氏名, 郵便番号, 電話番号 → 山田太郎, 0123456, 09012345678】

条件:
・原因の可能性が高い順に、2〜3個挙げる
・直す手順は、画面の操作名で番号付きで書く（バージョンによって名称が違う場合は、その旨も書く）
・元のCSVを上書きしないための注意を最初に入れる
・専門用語には短い説明を添える
```

## コピペで使えるプロンプト②：列ごとの形式を決める

取り込みの途中で「どの列をどの形式にするか」を決める場面があります。迷ったら、列の一覧をAIに渡して判断してもらいましょう。

```
次のCSVの列ごとに、Excelへ取り込むときのデータ形式（テキスト／数値／日付／標準）を提案してください。

【列名と中身の例を貼る（個人情報は架空の値に置き換える）】
【例: 会員番号 00123 / 郵便番号 0123456 / 金額 12,500 / 登録日 2026-04-01】

条件:
・理由を1行ずつ添える
・「先頭が0の数字」「ハイフン付きの番号」「桁数が長い数字」は、特に注意して判断する
・計算に使う列と、ただの識別番号の列を分けて考える
```

見分け方は単純です。**足したり平均したりする数字は「数値」、足し算しない番号（郵便番号・電話番号・会員番号）は「テキスト」**にします。

## コピペで使えるプロンプト③：すでに0が消えたファイルを直す

すでに保存してしまい、先頭の0が落ちたデータを直したいときもあります。桁数が決まっているもの（郵便番号は7桁、など）なら、関数で復元できます。

```
Excelで、先頭の0が消えてしまった数字を、決まった桁数に戻したいです。
次の条件に合うセルの式と使い方を教えてください。

【対象】【例: A列の郵便番号。本来は7桁。現在は「123456」のように6桁になっているものがある】
【直した値を入れたい場所】【例: B列】

条件:
・TEXT関数やREPT関数など、初心者でも使いやすい方法を1つ選ぶ
・式を入れる手順と、下の行へコピーする手順を書く
・直した値は「テキスト」として扱われるため、見た目は同じでも計算には使えない点を、注意として添える
```

ハイフン入りの電話番号は桁数が一定でないため、元のデータを取り直すほうが確実な場合もあります。

## 直したあとの4つのチェック

1. **行数と列数を元のCSVと突き合わせる**——取り込みで列がずれたり、カンマ入りの文字（「株式会社A, B」など）で分割されたりしていないか
2. **番号系の列の桁数を確認する**——郵便番号が7桁、電話番号が10〜11桁になっているか、数件だけでも目視する
3. **保存形式に注意する**——Excel形式（.xlsx）で保存した内容を、そのまま基幹システムに取り込むと失敗することがある。CSVに戻すときは、取り込み先が指定する文字コードを確認する
4. **個人情報をAIに貼らない**——顧客名簿の実データをそのまま貼るのは避ける。プロンプトに入れる列の例は、架空の値に置き換える（社内で外部AIサービスの利用ルールがある場合はそれに従う）

## まとめ

CSVの文字化けや先頭の0消えは、ファイルの不具合ではなく**Excelの自動判断**が原因です。ダブルクリックで開かず、取り込み機能で「文字コード」と「列ごとの形式」を指定する。自分の環境と症状をAIに伝えて、画面に合わせた手順を聞く。この流れで、ほとんどのケースは解決できます。

作業の前に元ファイルのコピーを取ること、直したあとに桁数を目視すること。この2つだけは忘れずに。

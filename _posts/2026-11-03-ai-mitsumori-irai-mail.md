「複合機の入れ替えで、3社に見積をお願いしたい」「イベント用の印刷物を新しい業者に頼みたい」——事務・総務の担当者になると、見積依頼のメールを書く機会が突然やってきます。

ところが、いざ書こうとすると手が止まります。何を書けば正確な見積が返ってくるのか分からない。相見積もりだと正直に書いていいのか迷う。そして、条件の書き漏れが原因で「数量はいくつですか？」「納期はいつですか？」と往復が始まり、気づけば3日経っていた、ということも珍しくありません。

この記事では、AIに見積依頼メールの下書きを作らせる方法を、**条件の材料の揃え方**を中心に紹介します。

## 見積依頼メールで往復が増える3つの原因

見積の返信が遅い、あるいは的外れになるのは、相手の問題ではなく依頼側の情報不足が原因のことが大半です。

1. **数量・仕様・納品先があいまい**——「チラシを印刷したい」だけでは、部数も紙の種類も分からず、金額が出せない
2. **期限が2種類あるのに1つしか書いていない**——「見積の回答期限」と「納品してほしい期限」は別物
3. **相見積もりかどうかを隠してしまう**——後から分かると、相手も条件の調整がしづらくなる

つまり、メールの文章力よりも「相手が見積を作るのに必要な材料を、最初に全部渡せているか」が勝負です。

## 解決の考え方：材料を6つ揃えてからAIに渡す

AIは材料があれば、丁寧で読みやすい文面に整えるのが得意です。逆に、材料がなければ「それらしい空欄だらけの例文」しか返せません。次の6つをメモしてから頼みましょう。

| 材料 | 例 |
|---|---|
| ①依頼する品・サービス | A4チラシの印刷、オフィスの備品、清掃業務など |
| ②数量・仕様 | 2,000部、両面カラー、紙は一般的な厚さ |
| ③納期・納品先 | 12月10日までに本社へ納品 |
| ④見積の回答期限 | 11月15日（金）までにご返信いただきたい |
| ⑤見積に含めてほしい項目 | 送料、データ作成費、消費税の別（税込・税別）など |
| ⑥相見積もりかどうか | 数社に依頼している／していない |

特に⑤は大事です。「送料は別途ですか」「税込ですか」を最初に指定しておくと、各社の金額を同じ条件で比べられます。

相見積もりの場合、「数社に見積をお願いしています」と**ひと言正直に書いて問題ありません**。むしろ書いたほうが、相手も現実的な金額を出しやすくなります。ただし、他社名や他社の金額は書かないのがマナーです。

## コピペ用プロンプト①：見積依頼メールを作る

【 】の中を書き換えて、ChatGPT・Copilot・Gemini・Claudeなど使い慣れたAIに貼り付けてください。

```
あなたは総務・購買の経験が豊富なビジネスメールの書き手です。
取引先に見積を依頼するメールの下書きを作ってください。

【自社名・部署・私の名前】【例: 株式会社サンプル 総務部 山田】
【宛先】【例: ○○印刷 営業担当 佐藤様。初めての取引／過去に取引あり】
【依頼する品・サービス】【例: 社内イベント用のA4チラシ印刷】
【数量・仕様】【例: 2,000部、両面カラー、データは当方で用意】
【納期・納品先】【例: 12月10日までに本社（東京都○○）へ納品】
【見積の回答期限】【例: 11月15日（金）】
【見積に含めてほしい項目】【例: 送料込み・税別で、内訳が分かる形】
【相見積もり】【例: 数社に依頼している／していない】

条件:
・件名は「【見積依頼】○○の件（社名）」の形で、3案出す
・本文は、挨拶→依頼の趣旨→依頼内容（箇条書き）→回答期限→不明点の問い合わせ先→結びの順にする
・依頼内容は箇条書きにして、数字と日付が目立つようにする
・相見積もりの場合は、他社名や金額には触れず、一文だけ添える
・押しつけがましい言い方は避け、300字〜450字程度に収める
・私が書いていない条件（予算、数量の増減の可能性など）は勝手に作らず、【要確認】と書く
```

最後の条件が重要です。AIは親切心から、書いていない予算や条件をそれらしく補ってしまうことがあるため、**「書いていないことは作らない」と明示**しておきます。

## コピペ用プロンプト②：見積の返信が来ないときの確認メールを作る

回答期限を過ぎても返信がないときは、責める形にならない確認が効果的です。

```
見積依頼メールへの返信がまだない相手に、確認のメールを書いてください。

【相手】【例: ○○印刷 佐藤様】
【依頼した日と内容】【例: 11月5日に、A4チラシ2,000部の見積を依頼】
【当初の回答期限】【例: 11月15日】
【こちらの事情】【例: 社内の発注判断が11月22日のため、それまでに必要】

条件:
・「お忙しいところ恐れ入ります」から始め、催促ではなく「状況確認」の姿勢にする
・前回のメールを見失っている可能性も考え、依頼内容を2行で再掲する
・新しい回答期限の希望を1つだけ示す（相手が決めやすいように）
・「辞退も可能です」という逃げ道も一文添える
・200字〜280字程度に収める
```

「辞退も可能」と添えると、相手も「忙しくて対応できない」と連絡しやすくなり、**返信がないまま宙ぶらりんになる状態**を避けられます。

## コピペ用プロンプト③：見積を断る・お礼を伝える

相見積もりでは、選ばれなかった会社にも連絡が必要です。結果の通知は事務が意外と後回しにしがちですが、次回の取引に響くこともあります。

```
相見積もりの結果、今回は見送ることにした会社へのお礼と、見送りの連絡メールを書いてください。

【相手】【例: ○○印刷 佐藤様】
【依頼した内容】【例: 社内イベント用チラシの印刷】
【見送りの理由として伝えられること】【例: 納期の都合／社内での総合判断】

条件:
・見積を作ってもらったことへの感謝を最初に書く
・理由は、伝えてよい範囲のみを簡潔に書く（他社名・他社の金額は書かない）
・「今後また機会があればご相談したい」という前向きな一文で締める
・200字前後で、冷たくならない文面にする
```

## 送る前に確認する4つのチェック

AIの下書きは、そのまま送らずに次の4点を見てください。

1. **数量・日付・金額の条件が、手元のメモと一致しているか**——特に回答期限と納期を取り違えていないか
2. **書いていない条件が混ざっていないか**——予算や特別な値引きの要望など、AIが補った言葉がないか
3. **他社名・他社の金額・社内の予算が入っていないか**——社外に出してはいけない情報は、プロンプトにも入れないのが安全です
4. **社内のルールに沿っているか**——一定金額以上は相見積もりが必要など、会社ごとの購買ルールは各社で異なるため、必ず自社の規程を確認してください

なお、契約条件や取引条件の取り扱いなど、法的な判断が必要な部分はAIに任せず、社内の担当部署や専門家にご確認ください。この記事は文面づくりのための方法であり、契約上の助言ではありません。

## まとめ

- 見積依頼メールが往復する原因は、文章力ではなく**材料の不足**
- ①依頼内容 ②数量・仕様 ③納期・納品先 ④回答期限 ⑤見積に含める項目 ⑥相見積もりの有無、の6つを揃えてからAIに渡す
- 「書いていない条件は作らず【要確認】と書く」と指示すると、勝手な補足を防げる
- 返信がないときの確認、見送りの連絡までセットでテンプレート化しておくと、次からは材料を入れ替えるだけで済む

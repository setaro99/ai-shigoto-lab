セミナーや異業種交流会、取引先の紹介の場で名刺を交換した。「あとでご挨拶のメールを」と思いながら、翌日、翌々日と過ぎ、気づけば名刺が机の上で眠っている——そんな経験はないでしょうか。

名刺交換後の挨拶メールは、**送る早さと、相手が「あの人か」と思い出せる一言**でほぼ決まります。ただ、初対面の相手に失礼のない文面を毎回ゼロから考えるのは意外と重い作業です。この記事では、AIに下書きを任せつつ、定型文に見えない挨拶メールを作る手順を紹介します。

## なぜ挨拶メールは後回しになるのか

後回しになる理由はたいてい次の3つです。

- 何を書けば「営業っぽくなく、でも覚えてもらえるか」の線引きがわからない
- 会話の内容を思い出すのに時間がかかる
- 相手との関係が浅く、敬語の距離感に自信が持てない

つまり、文章力の問題ではなく**材料が整理されていない**ことが原因です。材料さえ揃えば、AIは敬語の整えと構成を数十秒で仕上げてくれます。

## 解決の考え方：材料4点を先に書き出す

挨拶メールに必要な材料は、実は4つだけです。

1. **いつ・どこで会ったか**（日付と場の名前）
2. **相手が話していたこと**（1つだけで十分。例：新店舗の準備中、在庫管理の効率化に関心がある）
3. **自分がこの先できること**（情報共有、資料送付、また会って話したい、など）
4. **相手に求めたいこと**（今回は「特になし」でもよい。初回は“お願い”を入れないほうが自然です）

特に2が重要です。「貴重なお話をありがとうございました」だけでは誰にでも送れる文面ですが、「新店舗の準備のお話、印象に残っています」の一言があるだけで、相手の記憶が呼び起こされます。

メモが残っていない場合は、名刺の裏や手帳に書いた単語を並べるだけで構いません。AIが文章にしてくれます。

## コピペ用プロンプト①：当日送る基本の挨拶メール

次のプロンプトの【 】を埋めて、そのままAIに貼り付けてください。

```
あなたはビジネスメールの下書きを手伝うアシスタントです。
名刺交換をした直後に送る、初対面の相手への挨拶メールを書いてください。

【条件】
- 相手：【会社名・部署・氏名・役職】
- 会った場：【例：○月○日の△△セミナー終了後の名刺交換】
- 相手との会話で印象に残ったこと：【1〜2点。例：新店舗の準備中だと話していた】
- 自分の自己紹介（1文）：【会社名・担当業務】
- 今後の関わり方：【例：参考になりそうな資料があれば共有したい／機会があればまたお話ししたい】

【書き方のルール】
- 件名は「名刺交換のお礼（○月○日 △△セミナー）」のように、場と日付で思い出せる形にする
- 本文は200〜300字。冒頭で「いつ・どこで」を明記する
- 会話の内容に触れる一文を必ず1つ入れる。ただし、聞いていないことを推測で書かない
- 売り込み・商品の説明・面談の依頼は入れない
- 敬語は丁寧だが、かしこまりすぎない
- 署名欄には氏名・会社名・連絡先のプレースホルダーを置く

件名案を3つ、本文を1パターン出してください。
```

## コピペ用プロンプト②：紹介者がいる場合・次の機会につなげたい場合

知人の紹介で名刺交換をした場合や、「また会いたい」という意思を軽く添えたい場合は、こちらが使いやすいです。

```
次の条件で、初対面の相手への挨拶メールを書いてください。

- 相手：【会社名・氏名・役職】
- 紹介してくださった方：【氏名・関係】
- 会った場：【日付・場所・場面】
- 相手の関心ごと：【会話で出た話題】
- 自分から提供できる情報：【例：同じ課題に取り組んだ事例を簡単にまとめられる】

ルール：
- 紹介者への感謝を1文入れる
- 「ご都合のよいときに15分ほどお話しできれば」程度の、断りやすい控えめな提案にとどめる
- 相手に返信の義務を感じさせない書き方にする（「ご返信はお気遣いなく」など）
- 250〜350字

本文のあと、より短い（150字程度）バージョンも出してください。
```

## 使い方のコツ：AIに任せる範囲を決める

AIが得意なのは敬語の整えと構成です。一方で、**会話の事実**はAIにはわかりません。次の使い分けが安全です。

- 材料（会話の内容、日付、固有名詞）は自分で入力する
- AIには「文章化」と「トーンの調整」だけを任せる
- 出てきた文面の「印象に残ったこと」の部分は、自分の記憶と合っているか必ず確認する

「もう少しカジュアルに」「もっと短く」と追加で頼めば、相手との距離感に合わせて調整してくれます。

## 送る前のチェックリスト

- [ ] 相手の社名・部署・氏名・役職に誤字がないか（名刺と見比べる）
- [ ] 日付・場の名称が正しいか
- [ ] 会話の内容は、実際に相手が話したことか（AIの創作が混ざっていないか）
- [ ] 売り込みや、初対面には重い依頼が入っていないか
- [ ] 添付や参考URLを入れる場合、リンクが開けるか
- [ ] 送るタイミングは当日〜翌営業日中か（遅くとも2〜3日以内が目安）
- [ ] 個人情報や社外秘の話題に触れていないか

特に3つ目は大切です。AIは「気を利かせて」会話の内容を補ってしまうことがあります。事実と違う一文が入ると、かえって信頼を損ないます。

## 返信が来なかったときは

初回の挨拶メールは、返信が来なくても失敗ではありません。相手の業務が忙しいだけのことも多く、追いかけて催促する必要はありません。後日、相手の関心に沿った情報を共有できるときに、改めて連絡すれば十分です。

## まとめ

- 名刺交換後の挨拶メールは、**当日〜翌営業日に送る**ことと**「あの人か」と思い出せる一言**が肝心
- 先に材料4点（いつ・どこで／相手の話／自分ができること／求めること）を書き出す
- 事実はこちらで入力し、AIには文章化とトーン調整を任せる
- 初回は売り込まず、返信を求めすぎない

どんなメールも、材料さえ整っていれば数分で下書きが終わります。名刺が机で眠る前に、まず今日いただいた1枚から試してみてください。

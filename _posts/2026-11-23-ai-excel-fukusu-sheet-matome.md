「4月」「5月」「6月」……と月ごとにシートが分かれた売上表。年末に「1年分をまとめて集計して」と言われ、12枚のシートを1枚ずつ開いて、範囲を選んで、コピーして、貼り付ける。途中でどの月まで貼ったか分からなくなり、最初からやり直す——そんな経験はありませんか。

この記事では、**複数のシートに分かれた表を1枚にまとめる方法**を、AIに選んでもらい、手順ごと作ってもらうやり方を紹介します。ChatGPT・Copilot・Gemini・Claudeのどれでも使える形にしています。

## つまずくのは「方法が多すぎて、自分に合うものが分からない」から

「Excel 複数シート まとめる」で調べると、関数、統合機能、パワークエリ、マクロと、やり方がいくつも出てきます。どれも正しいのですが、次の条件によって向き不向きが変わります。

・**Excelのバージョン**：新しい関数は、古いバージョンでは使えません
・**シートの形がそろっているか**：列の並びが月によって違うと、単純に縦につなぐだけではずれてしまいます
・**一度きりか、毎月くり返すか**：今回だけならコピペに近い方法で十分ですが、毎月やるなら更新ボタン1つで済む仕組みのほうが楽です
・**欲しいのは「一覧」か「合計」か**：全行を縦に並べたいのか、同じ位置のセルを足し合わせたいだけなのかで、使う機能がまったく違います

解説記事を読み比べて自分の条件に合う方法を探すより、**条件をAIに伝えて方法を選んでもらう**ほうが早く済みます。

## 解決の考え方：AIに伝えるのは4つだけ

AIに頼むときは、次の4点を書き出します。

1. **シートの構成**：シートの枚数と名前、見出しが何行目にあるか、列の並び（A列=日付、B列=取引先……）
2. **そろっていない点**：月によって列が増えている、シートの途中に小計行や空白行がある、など
3. **ゴール**：全行を縦につないだ一覧が欲しいのか、項目ごとの合計が欲しいのか。元のシート名（何月分か）を列として残したいか
4. **環境とくり返し**：Excelのバージョン、今回限りか毎月か、マクロを使ってよい職場か

特に忘れがちなのが、3の**「どのシートから来た行か」を残すかどうか**です。まとめた後に「これは何月のデータ？」が分からなくなると、月別の集計ができません。日付の列がないシートなら、必ず残すように頼みましょう。

## コピペ用プロンプト①：自分に合う方法を選んでもらう

【】の部分を自分の表に合わせて書き換えてください。見出し行と、データを2〜3行だけ（社名や金額はダミーに置き換えて）貼ると、手順が具体的になります。

```
あなたはExcelに詳しいアシスタントです。
複数のシートに分かれた表を、1枚のシートにまとめたいです。
私の状況に合う方法を選び、手順を教えてください。

【シートの構成】
- 「4月」〜「3月」の12枚。シート名は月の名前
- どのシートも1行目が見出し、2行目からデータ
- 列の並び：A列=日付、B列=取引先名、C列=品名、D列=数量、E列=金額
- 行数は月によって違う（50〜200行くらい）

【そろっていない点】
- 10月以降のシートだけ、F列に「担当者」が追加されている
- 各シートの最終行に「合計」の行がある

【ゴール】
- 全シートのデータを縦につないだ一覧を「年間」シートに作りたい
- どのシートから来た行か分かるよう、シート名の列を付けたい
- 各シートの「合計」行と空白行は入れたくない

【環境】
- Excelのバージョン：【Microsoft 365 / Excel 2021 / 2019 / 分からない】
- この作業は【今回限り / 毎月くり返す】
- マクロ（VBA）の使用は【可 / 不可 / 分からない】

出力してほしいもの:
1. 候補になる方法を2〜3個と、それぞれの向き不向き（1行ずつ）
2. 私の状況に最も合う方法を1つ選び、その理由
3. 選んだ方法の手順（クリックする場所の順番まで。数式やコードはそのまま貼れる形で）
4. まとめた結果が正しいか確かめる方法

条件:
- 私はExcelの関数は使えますが、パワークエリとマクロは未経験です
- 元のシートは書き換えない方法にしてください
- バージョンによって使えない機能は、その旨を明記してください
```

「バージョンが分からない」と書いても構いません。その場合は「この数式を入れてエラーになったら、この機能は使えません」といった見分け方を添えてくれることが多いので、試した結果をそのまま伝えれば次の案に進めます。

## 返ってくる方法の見取り図

AIの回答を読むときの地図として、代表的な方法を整理しておきます。

・**縦につなぐ関数**：新しいExcelには、複数の範囲を縦に積み重ねる関数があります。数式1つで済み、元のシートを直せば結果も変わります。ただし使えるバージョンが限られます
・**パワークエリ**：ブック内のシートを読み込んで結合する機能です。最初の設定に少し手間がかかりますが、翌月からは「更新」を押すだけ。毎月くり返す作業に向いています
・**マクロ（VBA）**：シートを順番に開いてコピーする処理を自動化します。自由度は高い一方、職場によってはマクロ付きファイルが禁止されています
・**串刺し集計・統合機能**：全行の一覧は要らず、「各シートの同じセルの合計」だけ欲しいときの方法です。シートの形が完全に同じであることが前提です

「一覧が欲しい」のに串刺し集計を案内された、というように話がかみ合わないときは、ゴールの書き方があいまいになっています。「全行を縦に並べたい」「合計だけでよい」のどちらなのかを言い直してください。

## コピペ用プロンプト②：うまくいかなかったときの聞き直し

手順どおりにやっても、一度で思いどおりになるとは限りません。そのときは、起きたことをそのまま伝えます。

```
教えてもらった手順を試しましたが、うまくいきませんでした。
原因の候補と、確認する順番を教えてください。

【試した方法】（例：パワークエリでシートを結合）
【どこまで進んだか】（例：手順4の「結合」まで）
【起きたこと】（例：10月以降の行だけ列が1つずれている／0が並んだ行が大量に入る／エラーメッセージ「〜」が出た）
【期待していた結果】（例：全月で列がそろった一覧）

条件:
- 原因の候補は可能性が高い順に並べる
- 元のシートを直す方法と、まとめる側で吸収する方法の両方があれば分けて書く
```

よくあるのは、月によって列の数が違う、空白行が「0」として入ってしまう、見出し行が月の数だけ混ざる、の3つです。どれも「起きたこと」に具体的に書けば、直し方を教えてもらえます。

## コピペ用プロンプト③：来月の自分のために手順を残す

まとめ終えたら、最後にこの一言を足しておくと、次回の作業が楽になります。

```
今回うまくいった手順を、来月の自分や後任が読んで再現できるよう、
番号付きの作業手順にまとめてください。
新しい月のシートを追加したときにやること、やってはいけないこと
（シート名の付け方、列の追加など）も3つ以内で書いてください。
```

できた手順は、ブックの先頭に「使い方」シートを作って貼っておくと、ファイルと一緒に引き継げます。

## 使う前のチェック

まとめた表をそのまま集計や報告に使う前に、次の点を確かめてください。

□ **行数が合っているか**：各シートのデータ行数を足した数と、まとめた表の行数が一致するか。合わないときは、行が欠けているか、合計行・見出し行が混ざっています
□ **合計が合っているか**：金額の列の合計が、各シートの合計を足した値と一致するか。行数が合っていても、列がずれて別の列を足していることがあります
□ **最初と最後の月を目で見たか**：先頭のシートと末尾のシートが抜けやすい場所です。4月と3月のデータが入っているかを確認します
□ **二重に入っていないか**：手順をやり直したときに、同じ月が2回入っていないか。月ごとの件数を数えると見つけやすくなります
□ **元のファイルを残したか**：作業はコピーしたファイルで行い、元のブックは書き換えずに保管しておきます
□ **AIに貼る情報は必要最小限か**：見出しと列の並びが分かれば手順は作れます。取引先名や個人名、金額の実データは貼らず、ダミーに置き換えてください。会社のAI利用ルールにも従いましょう

AIが教えるメニュー名やボタンの位置は、Excelのバージョンによって実際の画面と違うことがあります。見つからないときは「その項目が画面にありません。リボンにはこう表示されています」と伝えれば、別の行き方を案内してもらえます。

## まとめ

複数シートを1つにまとめる作業は、方法を知らないとコピペのくり返しになり、方法を調べ始めると選択肢の多さで迷います。

・AIに伝えるのは「シートの構成・そろっていない点・ゴール・環境」の4つ
・「一覧が欲しい」のか「合計だけでよい」のかを最初にはっきりさせる
・どのシートから来た行かを列として残すよう頼む
・行数と合計の2つで必ず検算する
・うまくいった手順は文章にして、ブックの中に残しておく

年度末や年末の集計は、毎年同じ時期に同じ苦労をしがちな作業です。今年のうちに「更新するだけ」の形にしておくと、来年の自分が助かります。まずはシートの構成を4行で書き出すところから始めてみてください。

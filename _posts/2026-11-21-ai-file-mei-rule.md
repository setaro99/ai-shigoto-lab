共有フォルダを開くと、「見積書_最新.xlsx」「見積書_最新(2).xlsx」「見積書_修正版_山田確認済.xlsx」が並んでいる。どれが本当の最新なのか、開いて更新日時を見比べないと分からない。年末の書類整理や、異動前の引き継ぎのたびに同じことで時間を取られていませんか。

この記事では、**部署で使うファイル名の命名ルール**をAIと一緒に決め、メンバーに周知し、既存ファイルを整えるところまでを紹介します。特別なツールは使わず、ChatGPT・Copilot・Gemini・Claudeのどれでも使える形にしています。

## ファイル名が乱れるのは「ルールが頭の中にしかない」から

ファイル名がばらばらになる原因は、だらしなさではありません。多くの場合、次のどれかです。

・**並べ方の決まりがない**：日付を先に書く人、案件名を先に書く人がいて、フォルダ内で並び順がそろわない
・**「版」の表し方が人によって違う**：「最新」「修正」「v2」「確定」が混在し、どれが最終版か判断できない
・**ルールはあるが書かれていない**：先輩の真似で何となく守られているだけで、新しく来た人には伝わらない

つまり、必要なのは「きれいに整える作業」よりも先に、**誰が見ても同じ名前を付けられる決まり**を1枚の文書にすることです。この「決まりを言葉にする」作業こそ、AIが得意とするところです。

## 解決の考え方：要素・順番・書き方の3点だけ決める

命名ルールは、凝りすぎると守られなくなります。決めるのは次の3点に絞りましょう。

1. **要素**：ファイル名に入れる情報（例：日付、取引先名、書類の種類、版）
2. **順番**：要素を並べる順序と区切り文字（例：「20261121_取引先名_見積書_v02」）
3. **書き方**：日付の桁数、全角か半角か、使わない言葉（「最新」「コピー」は使わない、など）

ポイントは、**日付を「20261121」のように8桁で先頭に置く**と、名前順に並べるだけで時系列になることです。また、「最新」は翌日には最新ではなくなるため、版は「v01」「v02」のように番号で表すほうが混乱しません。

この3点を、自分の部署で扱う書類の実例をもとにAIに組み立ててもらいます。

## コピペ用プロンプト①：部署の命名ルールを作る

【】の部分を自分の職場に合わせて書き換えて使ってください。実際のファイル名を5〜10個貼ると、現状に合った提案が出やすくなります。

```
あなたは事務部門の業務改善を手伝うアシスタントです。
共有フォルダのファイル名の命名ルールを作りたいので、以下の条件で案を出してください。

【部署・業務】営業事務（見積書・請求書・議事録・社内資料を扱う）
【主な書類の種類】見積書、請求書、発注書、議事録、提案資料
【現在のファイル名の例】
- 見積書_最新.xlsx
- 〇〇商事様見積もり修正2.xlsx
- 1121議事録.docx
- 提案資料（山田さん確認済み）.pptx
【困っていること】どれが最新版か分からない、並び順がばらばら
【守ってほしい人】パソコンに詳しくない人も含む部署メンバー8名

出力してほしいもの:
1. ファイル名に入れる要素と並べる順番（区切り文字も含む）
2. 日付・版・取引先名の書き方の決まり
3. 使わない言葉・記号の一覧と、その理由
4. 書類の種類ごとの命名例（各2つ）
5. 上の「現在のファイル名の例」を新ルールで付け直した例

条件:
- ルールは5項目以内に収め、覚えやすさを優先する
- 半角・全角の使い分けを明記する
- WindowsとMacのどちらでも問題が起きにくい記号だけを使う
```

AIが出した案は、そのまま採用せず「うちの部署で本当に守れるか」で削ってください。要素が5つを超えるようなら、フォルダ分けで代わりにできないか（取引先ごとにフォルダを分ければ、ファイル名から取引先名を外せる、など）も聞いてみると、すっきりします。

## コピペ用プロンプト②：周知文と1枚のルール表にする

ルールが決まったら、メンバーに伝える文章にします。ルールだけを送っても読まれにくいので、「なぜ変えるのか」と「いつから」を添えるのがコツです。

```
以下の命名ルールを部署メンバーに周知したいです。
社内チャットに投稿する短い周知文と、共有フォルダの先頭に置く「ルール表」を作ってください。

【命名ルール】
（プロンプト①で決めたルールをここに貼る）

【適用開始日】12月1日から作成・更新するファイル
【既存ファイルの扱い】今年度分のみ年内に担当者が付け直す。それ以前はそのまま
【問い合わせ先】営業事務 担当：【自分の名前】

条件:
- 周知文は300字以内。変える理由を1文で添える
- ルール表は見出し・ルール・良い例・悪い例の4列の表にする
- 命令口調を避け、協力をお願いする言い方にする
```

ルール表はフォルダの一番上に来るように「00_ファイル名ルール」のような名前で保存しておくと、迷ったときにすぐ開けます。

## コピペ用プロンプト③：既存ファイルの名前を一括で整える

すでにあるファイルの名前を1つずつ直すのは大変です。ファイル名の一覧をAIに渡して、新ルールでの名前を対応表にしてもらいましょう。一覧は、フォルダ内のファイルを全選択してパスをコピーする、エクスプローラーの「名前」欄をコピーするなどの方法で取り出せます。

```
以下は共有フォルダにある既存ファイルの名前の一覧です。
先ほどの命名ルールに沿った新しいファイル名を考え、
「現在の名前」「新しい名前」「判断に迷った点」の3列の表で出してください。

【命名ルール】
（ルールを貼る）

【ファイル名の一覧】
（ここに一覧を貼る）

条件:
- 日付がファイル名から読み取れない場合は推測せず「要確認」と書く
- 同じ書類の版違いと思われるものは、版番号の付け方を提案する
- 拡張子は変えない
```

「要確認」になったファイルは、更新日時や中身を見て自分で判断します。AIは中身を見ていないので、ここを任せきりにしないことが大切です。

## 使う前のチェック

ルールを決めて運用を始める前に、次の点を確かめてください。

□ **社内に既存のルールがないか**：情報システム部門や文書管理規程で、すでに命名ルールや保存場所が決まっていることがあります。部署独自のルールと食い違わないか確認しましょう
□ **リンク切れが起きないか**：ファイル名を変えると、Excelの別ファイル参照、ショートカット、メールやチャットに貼ったリンクが開けなくなる場合があります。重要なファイルは、名前を変える前に参照元を確認してください
□ **ファイル名が長すぎないか**：要素を詰め込むと、フォルダの階層と合わせて長くなり、開けない・コピーできないといった不具合の原因になります
□ **機密情報を入れていないか**：AIに貼るファイル名一覧に、個人名や未公表の取引情報が含まれていないか確認し、必要なら「取引先A」などに置き換えてから渡します。会社のAI利用ルールにも従ってください
□ **全員が守れる量か**：最初は「日付8桁を先頭」「版はv番号」の2つだけでも十分です。定着してから足していきましょう

## まとめ

ファイル名の乱れは、一度きれいに整えても、ルールが言葉になっていなければすぐに元に戻ります。

・決めるのは「要素・順番・書き方」の3点だけ
・日付は8桁で先頭、版は「最新」ではなく番号で
・AIには、ルール案づくり・周知文・既存ファイルの付け直し案までを任せる
・中身の判断、リンク切れの確認、社内ルールとの整合は自分で行う

年末の書類整理や、引き継ぎ書を作るタイミングは、命名ルールを見直すよい機会です。まずは自分が一番よく触るフォルダから試してみてください。

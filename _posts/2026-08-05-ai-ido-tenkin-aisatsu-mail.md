「異動が決まった。お世話になった人たちに挨拶メールを送らないと」——このとき、退職とは違う難しさに気づきます。会社を離れるわけではないので、感謝だけで終わらせるわけにもいかず、かといって大げさに書くのも違う気がする。新しい部署や勤務地への異動という「前向きな報告」と「感謝」のバランスをどう取ればいいか、意外と迷うのです。

この記事では、異動・転勤の挨拶メールを、社内向け・取引先向けでAIを使って書き分ける方法を、コピペで使えるプロンプト付きで紹介します。

## 異動の挨拶メールが難しい理由は「退職メールとの混同」

異動・転勤の挨拶メールで手が止まる人の多くは、退職メールの書き方を無意識に流用しようとしています。しかし異動と退職では、書くべき内容が根本的に違います。

・会社は辞めないので、大げさな感謝や「最後に」といった表現は不要
・後任者への引き継ぎだけでなく、「異動先でも連絡を取り合える」ことを伝える必要がある
・取引先向けには、担当変更後も会社としての取引は継続することを明確にする

この違いを意識せず退職メールのトーンで書いてしまうと、「もう会えなくなる」ような誤解を与えたり、逆に社内向けなのに他人行儀すぎたりします。書くべきは「感謝」「異動の報告」「後任者への橋渡し」の3点だけです。

## 送る相手で変える「型」を先に押さえる

具体的なプロンプトの前に、相手別の構成を整理しておきます。

**社内向け（同僚・関係部署への一斉送信）**

1. **異動の報告** — 異動日・異動先の部署（勤務地が変わる場合は新勤務地も）
2. **在籍中の感謝** — お世話になったことへの感謝を簡潔に
3. **後任者の紹介（担当業務がある場合）** — 氏名と引き継ぎ状況
4. **結びの挨拶** — 異動後も変わらぬお付き合いをお願いする一文

**取引先向け（担当者宛の個別送信）**

1. **異動の報告と感謝** — 担当していた期間への感謝を添える
2. **後任者の紹介** — 氏名・連絡先・引き継ぎの完了時期
3. **取引継続への安心感** — 会社としての対応に変わりがないことを伝える
4. **今後の関係を示す一言** — 異動先からも縁があれば連絡したい旨（任意）

社内向けは異動先での抱負を添えると温かみが出ますが、取引先向けは「業務が滞らない」という安心感を優先するのがポイントです。

## コピペで使えるプロンプト（社内向け）

以下をAIに貼り付け、【 】の中だけをあなたの状況に書き換えてください。ChatGPT・Copilot・Gemini・Claude、どれでも動きます。

```
あなたは日本企業の慣習に詳しいビジネスメールの専門家です。
異動する社員が社内の同僚・関係者へ送る挨拶メールを書いてください。

・異動日: 【2026年9月1日】
・異動元/異動先: 【営業部から、大阪支店の営業企画部へ】
・在籍期間: 【現部署に4年間在籍】
・宛先: 【社内の同僚・関係者全員（一斉送信）】
・伝えたいこと: 【一緒に仕事ができたことへの感謝と、異動先での抱負】

条件:
・退職メールのような大げさな別れの表現は使わない
・「異動の報告→在籍中の感謝→異動先での抱負→結びの挨拶」の順で
・前向きで簡潔な文体で200字前後
・件名も1案つける
```

## コピペで使えるプロンプト（取引先向け）

取引先には、感謝に加えて「担当は変わっても取引に支障はない」という安心感を伝えることが欠かせません。

```
あなたはBtoB取引に強いビジネスメールの専門家です。
異動する担当者が取引先へ送る挨拶メールを書いてください。

・異動日: 【2026年9月1日】
・これまでの取引関係: 【2年間、〇〇社様の窓口を担当】
・後任者: 【同部署の△△、連絡先は本メールに記載】
・引き継ぎ状況: 【主要な案件はすでに後任へ共有済み】

条件:
・退職の挨拶と誤解されないよう、異動である旨を最初に明記する
・「感謝→後任者の紹介→引き継ぎの見通し→今後のお願い」の順で
・丁寧だが事務的になりすぎない文体で250字前後
・件名も1案つける
```

## 送信前に必ず確認する3点

AIが作った文面はそのまま使えることが多いですが、送信前に次の3点は自分の目で必ず確認してください。

・**「退職」と誤解される表現が残っていないか** — AIは文脈によって「今までお世話になりました」を退職メール風に強調しすぎることがあります。異動日と異動先を冒頭で明記し、会社を離れるわけではないことを明確にしましょう
・**後任者の連絡先が正確か** — 取引先向けメールでは、後任者のメールアドレスや電話番号に誤りがあると、その後のやり取りが滞ります。送信前に後任者本人にも文面を確認してもらうと安心です
・**社内ルールに沿ったタイミングか** — 異動の社外公表は、会社の方針で正式発表後と決まっていることが多いです。上長に確認してから、取引先向けメールを送るべきタイミングかどうかを見直しましょう

## まとめ

異動・転勤の挨拶メールは、退職メールとは違う「感謝」「報告」「橋渡し」の3点さえ押さえれば、社内向け・取引先向けのどちらもAIが数十秒で下書きしてくれます。あなたがやるべきことは、ゼロから言葉を考えることではなく、退職メールと混同されていないか、後任者の情報が正確か、送るタイミングが会社のルールに沿っているかを確認するだけです。これだけで、忙しい異動前の準備の中でも、挨拶メールだけは気持ちよく送り出せます。
